## 防御・ライフ性能変更

`cns/observ.cns`を開き、ファイル先頭を確認してください。

### 自動回復量

1 gametime ごとに回復するLifeを設定する。

```ini
;; 自動回復量（最大127）
var(12)=var(12)|(1*           0) ; ここの 0 を変更
```

- 変更する数値：式の末尾にある`0`
- デフォルト：`0`。自動回復しない
- 設定範囲：`0`〜`127`
- 設定例：`1*5`にすると、1 gametime ごとにLifeを`5`回復する

### ダメージ減衰率

極大Damage閾値未満の攻撃に対して、現在Lifeによる減衰を適用する前に、元Damageへ掛ける割合を設定する。設定値の1段階は元Damageの`4%`である。

```ini
;; ダメージ減衰率（最大25、1段階4%）
var(12)=var(12)|(128*         4) ; ここの 4 を変更
```

- 変更する数値：式の末尾にある`4`
- デフォルト：`4`。元Damageの`16%`
- 設定範囲：`0`〜`25`
- `0`は`0%`、`1`は`4%`、`10`は`40%`、`25`は`100%`
- 最終的な削り値には、現在Lifeに応じた連続的な減衰も適用される

### 無敵時間

攻撃を受け付けた後、次のDamageを受け付けない時間を設定する。

```ini
;; 無敵時間（最大127tick）
var(12)=var(12)|(4096*       30) ; ここの 30 を変更
```

- 変更する数値：式の末尾にある`30`
- デフォルト：`30tick`
- 設定範囲：`0`〜`127tick`
- `0`にすると、設定による無敵時間を付与しない

### 極大Damage閾値

通常のDamage減衰を適用せず、元Damageをそのまま受ける境界を設定する。設定値の1段階は`100Damage`である。

```ini
;; 極大Damage閾値（最大32、1段階100Damage）
var(12)=var(12)|(1048576*    30) ; ここの 30 を変更
```

- 変更する数値：式の末尾にある`30`
- デフォルト：`30`。`3000Damage`以上を減衰しない
- 設定範囲：`0`〜`32`
- 設定例：`1048576*10`にすると、`1000Damage`以上を減衰しない
- `0`にすると、極大Damage判定を無効化する

## AI

AIの設定は、`cns/observ.cns`の先頭付近にある次の箇所で変更する。

```ini
;; AI 利用したい場合は trigger1=1 に指定
trigger1=0
trigger2=palno=[6,12]
```

- デフォルト：`trigger1=0`。AIを常時有効化しない
- パレット自動有効化：パレット`6`〜`12`でAIを有効にする
- AI常時有効化：`trigger1=0`を`trigger1=1`へ変更する

## 技

- `X+Y`：回避
- `前+C`：前方近距離ワープ
- `後ろ+C`：後方近距離ワープ

- `236+A`（下、斜め前、前＋A）または`26+A`（下、前＋A）：画面横断突進。後方画面外での30tick待機中にキャラクター基準の前（→）・上（↑）・後（←）を一度入れると、それぞれ45度・90度・275度へ分岐する。分岐入力がなければ並行突進。
- `22+A`（下、下＋A、30tick受付）：汎用両手光弾発出
- `22+B`（下、下＋B、30tick受付）：汎用片手光弾発出

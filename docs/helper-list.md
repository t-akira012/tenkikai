# ヘルパー一覧

この文書は、TENKIKAIの定義ファイルにある `Helper` コントローラーを列挙する。StateDefとしてのヘルパーの挙動は[ヘルパーステート](state-helper.md)を参照する。

## 頭部ヘルパー

| 項目 | 定義 |
| --- | --- |
| 生成元 | `t-observ.cns` のStateDef `-3` |
| 生成条件 | 本体であり、ID `99001` のヘルパーが存在しないとき |
| 名前 | `the_head` |
| ID | `99001` |
| 初期Action | `99001` |
| 種別 | `player` |
| Pause中の活動時間 | `99990000000` tick |
| SuperPause中の活動時間 | `99990000000` tick |

常時監視から本体に1体だけ生成される。生成後はStateDef `-2` によってStateDef `99000` へ移され、StateDef `99001` で頭部表示として待機する。本体のX座標と、本体より61ピクセル上を基準にした正弦波のY座標へ毎tick追従する。

## 集計

`Helper` コントローラーは1個、明示されたヘルパーIDは `99001` の1種類である。

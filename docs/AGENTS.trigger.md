# Trigger記述規則

## `command` 規則

### `command` は `StateDef -1` に限り利用すること

WinMUGENでは、キャラクターは自動操作されるモードがある。

自動操作中には `command` は発動しない。状態処理の Trigger に `command` を利用すると、処理に失敗するため `StateDef -1` の ChangeState に限り利用すること。

### 入力非依存処理での `command` 禁止

`command` はプレイヤーの明示的な入力を処理する条件にのみ使用する。StateDef `-2`、StateDef `-3`、および入力がなくても成立すべき処理の条件に `command` を使用してはならない。

入力非依存処理には、`-2/-3` だけでなく、通常ステート内の重力・接地・状態同期・自動復帰・被弾処理なども含む。これらはAI・自動操作、入力を伴わないState遷移、被弾、State奪取からの復帰、ラウンド開始などでも成立しなければならない。入力情報である `command` に依存すると、条件が成立せず処理が停止する。

入力非依存処理の判定には、StateNo、StateType、位置、速度、時間、専用変数など、入力に依存しない状態情報を使用する。

### `triggerall` と `command`

`triggerall` に `command` トリガーを記述してはならない。

キャラクターの自動操作時には `command` トリガーが機能しないため、`triggerall=command=...` を前提にした条件は成立しない。`command` を使用する場合は、実際に入力遷移を評価する個別の `trigger1`、`trigger2` などへ記述する。

自動操作にも対応させる必要がある処理では、`command` 以外の状態・位置・時間などのトリガーを使用する。

# Varのラウンド持ち越し

## 調査結果

ラウンドをまたぐと、変数はFile-/CNSファイルにある `IntPersistIndex` と `FloatPersistIndex` の設定値に従って0へリセットされる。

リセット対象は、設定値より小さい番号の変数スロットである。

例えば設定値が `30` の場合は、変数 `0`～`29` がリセットされ、変数 `30` 以降は次のラウンドへ持ち越される。

## 持ち越されない値

- `SysVar` と `SysFvar` は一切持ち越されない。
- 別の試合へ変数を持ち越すことはできない。
- State Controller とHelperはラウンド終了時点で消去されるため、それらが保持する変数を持ち越すことはできない。

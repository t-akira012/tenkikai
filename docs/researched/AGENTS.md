# 調査情報文書の規約

## 公式文書との重複

このディレクトリには、公式ドキュメントに記載されていないユーザー調査情報だけを記載する。

公式ドキュメントに記載されている情報は追記しない。既存文書に公式ドキュメントの情報が含まれている場合は削除する。

一般的な用法、利用上の助言、記述例、管理方法、TempVarなどの運用ノウハウは追記しない。記載内容は、ユーザー調査で確認された仕様事項に限る。

# デフォルトステート

この文書は、`t-command.cmd` と `t-state.cns` にある、攻撃以外のTENKIKAI固有ステートを説明する。WinMUGENの共有ステートは[stcommon共有ステート](state-stcommon.md)を参照する。

## StateDef -1: 入力によるステート遷移

毎tick入力を判定し、現在の状態から実行するStateDefを決める。判定順は、超必殺技、必殺技、ダッシュ、投げ、立ち通常技、挑発、しゃがみ通常技、空中通常技である。先に成立した `changestate` が以降の判定を打ち切るため、上にある技ほど入力競合時の優先度が高い。

`var(1)` は必殺技へ移行できる条件を表す。一度0へ戻した後、空中以外で操作可能な場合、またはStateDef `200～299`・`400～499` の通常技が接触した場合に1となる。足払いのStateDef `440` はキャンセル元から除外される。

超必殺技は1000以上、同時押し版必殺技は330以上のパワーを要求する。通常技同士にも個別の連係条件がある。詳細は[アタックステート](state-attack.md)と[超必殺技ステート](super-attack.md)を参照する。

## 前方ダッシュ

前方向を2回入力すると開始する。走行速度を継続して与える方式ではなく、表示変形、100ピクセルの瞬間移動、10tickの不可視時間、終了モーションで構成される。

### StateDef 100: 前方ダッシュ開始

Action `100` を再生し、序盤から中盤にかけて横方向の表示倍率を変化させる。アニメーション終了時にX座標へ100を加え、StateDef `102` へ移る。

### StateDef 102: 前方ダッシュ不可視待機

キャラクターを不可視にしたまま10tick待機し、StateDef `101` へ移る。

### StateDef 101: 前方ダッシュ終了

Action `101` を再生する。アニメーション終了時にStateDef `0` へ戻り、操作を可能にする。

## 後方ステップ

後ろ方向を2回入力すると開始する。前方ダッシュと同様、100ピクセルの瞬間移動と10tickの不可視時間を使う。

### StateDef 105: 後方ステップ開始

Action `105` を再生し、終了時にX座標へ-100を加えてStateDef `107` へ移る。

### StateDef 107: 後方ステップ不可視待機

キャラクターを不可視にしたまま10tick待機し、StateDef `106` へ移る。

### StateDef 106: 後方ステップ終了

Action `106` を再生する。アニメーション終了時にStateDef `0` へ戻り、操作を可能にする。

## 勝利

### StateDef 180: 勝利ステート決定

開始直後にStateDef `181` へ移る。勝利演出の入口として機能する。

### StateDef 181: 勝利ポーズ

Action `181` を再生し、全属性の攻撃を常時無効化する。別ステートへの自動遷移は定義されておらず、ラウンド終了処理に任せる。

## StateDef 191: 登場

WinMUGEN共有のStateDef `190` から移行する登場ステートである。Action `190` を再生し、`Intro` フラグを維持する。

ラウンド開始後にAction `191` の飛翔物を画面右側へ生成し、Action `192` の演出物も本体付近から生成する。Action要素7で共通効果音を2種類再生する。登場アニメーション終了時にStateDef `0` へ戻る。

## StateDef 195: 挑発

スタートボタンを押し、空中以外で操作可能なときに開始する。Action `195` を再生し、40tick目に操作を返す。アニメーション終了時にもStateDef `0` へ戻り、操作を可能にする。

# 技の階層スキーマ

版付きの基準値は[技分類デフォルト一覧](defaults/README.md)を参照する。

## 基本構造

```text
技
├─ 1. 演出
│  ├─ 1-1. 本体の動作
│  ├─ 1-2. 飛び道具・衝撃波などの主表現
│  └─ 1-3. 付随エフェクト
└─ 2. 攻撃定義
   ├─ 2-1. 攻撃
   │  ├─ 2-1-1. 判定
   │  ├─ 2-1-2. 威力・リソース
   │  ├─ 2-1-3. 攻撃属性
   │  ├─ 2-1-4. 防御突破特性
   │  └─ 2-1-5. 持続・再命中・相殺
   ├─ 2-2. 発動時効果
   │  ├─ 2-2-1. 無敵
   │  ├─ 2-2-2. アーマー
   │  ├─ 2-2-3. ReversalDef（当て身）
   │  ├─ 2-2-4. 移動・ワープ・位置制御
   │  └─ 2-2-5. その他の発動制御
   └─ 2-3. 命中時作用
      ├─ 2-3-1. 通常命中時作用
      ├─ 2-3-2. ガード時作用
      └─ 2-3-3. 特殊命中時作用
```

## 項目の責務

### 1. 演出

#### 1-1. 本体の動作

入力から終了までの姿勢、Action、移動、浮遊、向き、発生、持続、後隙、復帰、中断を記録する。

#### 1-2. 飛び道具・衝撃波などの主表現

技の中心となるHelper、Projectile、衝撃波、射出物の生成、位置、軌道、速度、寿命、消滅を記録する。

#### 1-3. 付随エフェクト

暗転、発光、残像、音、画面振動、補助Explodなど、主表現を補強する要素を記録する。

### 2. 攻撃定義

#### 2-1. 攻撃

- `2-1-1 判定`：攻撃主体、範囲、対象、発生、持続
- `2-1-2 威力・リソース`：ダメージ、削り、Power増減、Juggle
- `2-1-3 攻撃属性`：通常・必殺・超必殺、立ち・屈み・空中、ガード方向、優先度
- `2-1-4 防御突破特性`：アーマー、無敵、ガード、Projectile防御、ReversalDefへの具体的作用
- `2-1-5 持続・再命中・相殺`：再命中間隔、命中回数、消滅、相殺関係

#### 2-2. 発動時効果

- `2-2-1 無敵`：対象属性と有効期間
- `2-2-2 アーマー`：耐久、受付間隔、解除条件
- `2-2-3 ReversalDef`：受付対象、成功条件、成功時遷移
- `2-2-4 移動・ワープ・位置制御`：Rootと攻撃主体の移動および拘束
- `2-2-5 その他の発動制御`：PlayerPush、Power消費、Ctrl、キャンセル、使用・中断条件

#### 2-3. 命中時作用

- `2-3-1 通常命中時作用`：硬直、速度、吹き飛び、ダウン、State変更
- `2-3-2 ガード時作用`：ガード硬直、押し戻し、削り、ガードクラッシュ
- `2-3-3 特殊命中時作用`：投げ、拘束、追撃許可、固有State、Target操作

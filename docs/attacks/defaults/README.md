# 技分類デフォルト候補一覧

このディレクトリの値と挙動は自動適用するデフォルトではなく、試験実装用としてユーザーへ提案できる版付き候補である。版名、適用項目および具体値を提示し、ユーザーが明示承認した範囲だけを試験値として採用する。未確定事項を候補値で補完してはならない。

Powerの消費、増加、取得、相手への付与および固定は候補へ含めない。ユーザーが具体値を指定するか、独立して提示された試験値を明示承認した場合だけ個別技仕様へ記録し、実装する。

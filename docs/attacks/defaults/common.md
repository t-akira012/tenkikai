# common-v1

## 根拠

KFMの通常攻撃、必殺技、投げ、超必殺に共通する構造を基準とする。個別数値は分類プロファイルで上書きする。

## 試験候補

- 技中は`ctrl = 0`とし、終了時に待機系Stateへ復帰してCtrlを返す。
- 攻撃はガード可能とする。
- アーマー貫通、無敵貫通、ガードクラッシュ、Projectile防御貫通は付与しない。
- 無敵、アーマー、ReversalDefは付与しない。
- 相手固有Var、Helper、独自アーマー仕様へ依存しない。
- 単発攻撃を基本とし、多段、再命中、相殺は分類プロファイルまたはユーザー指定で解決する。
- 攻撃成功時に相手Stateを奪わない。投げなど分類上必要な場合だけ上書きする。
- 発生、持続、後隙、ClsnはTENKIKAIのActionと個別設計から解決する。
- 本体移動はTENKIKAIの移動・速度管理規約に従い、KFMの`PosAdd`をそのまま移植しない。

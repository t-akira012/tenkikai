# 001: 画面横断突進

## 基本情報

- 状態：設計中
- StateDef：`1200`〜`1204`
- 予約範囲：`1200`〜`1299`
- 入力：`X`単押し、入力bit 4・マスク値`16`
- 技分類：突進
- 使用デフォルト：`common-v1`、`rush-v1`

## ユーザー要求

通常時の`X`オーラバウンド確認を新規の突進技へ置き換える。既存の`X`処理は確認用途だけであるため、上書きしてよい。異形回避中の`X`による出現位置選択は維持する。

発動すると、現在位置から現在の向きに対する後方の画面外へ、本体自由傾斜を使用した後方ダッシュで移動する。開始位置にかかわらず、後方画面外へは5tick以内に到達する。

後方画面外へ到達した後は30tick不在となる。その後、本体自由傾斜によってほぼ横倒しになり、通常の前方ダッシュの2.5倍の速度で前方へ突進する。後方画面外から画面全体を横断し、進行方向側の反対画面外まで抜ける。

Root原点が画面内へ侵入した瞬間に、背景だけを黒く暗転する。3tickで暗くなり、通常明度の25%となるピークを5tick維持し、3tickで通常明度へ戻る。

同じ画面侵入時に、突進開始高度を中心として画面を横断する横線形衝撃波を発生させる。細い横線を上下対称へ拡大し、消滅時は徐々に透明にする。

反対側の画面外へ抜けた後も45tickは同じ方向へ移動を続け、45tick経過時に停止して復帰する。

横断後は、現在の向きと反対側にある画面端から40px内側へ位置を確定し、異形回避の復帰を複製した突進専用の5tick復帰によって通常状態へ戻る。異形回避復帰と突進復帰は概念的に異なるため倍率計算を分離し、時間管理だけを本体アニメーション変更・時間付き処理予約として共通化する。

## 解決済み仕様

### 1. 演出

#### 1-1. 本体の動作

##### StateDef 1200：後方画面外への退避

- `X`入力による技入口とする。通常時のStateDef `4001`への遷移を本StateDefへの遷移へ置き換える。（ユーザー指定）
- 発動時の向きは変更しない。（ユーザー指定）
- 発動時の高度を維持し、水平に移動する。（ユーザー指定の動作から解決）
- 現在の向きに対する後方の画面外へ、途中経路を表示する連続移動で退避する。（ユーザー指定）
- 画面内のどの水平位置から開始しても、最大5tick以内に後方画面外へ到達する。（ユーザー指定）
- 本体自由傾斜は後方ダッシュと同じ方向へ要求する。（ユーザー指定）
- 後方画面外へ到達した時点でStateDef `1203`へ移る。（ユーザー指定）

##### StateDef 1203：突進前の画面外不在

- 後方画面外で水平・垂直速度を停止する。（ユーザー指定）
- 30tickの不在後にStateDef `1201`へ移る。（ユーザー指定）

##### StateDef 1201：画面横断突進

- StateDef `1203`から向きと高度を維持して開始する。（ユーザー指定）
- 本体自由傾斜によって、進行方向へほぼ横倒しになる姿勢へ移行する。（ユーザー指定）
- 前方ダッシュの目標X速度`12`の2.5倍である`30px/tick`で、向いている方向へ水平移動する。（ユーザー指定）
- 後方画面外から画面全体を横断し、進行方向側の画面外へRootが抜けるまで継続する。（ユーザー指定）
- Root原点が画面外から画面内へ侵入した瞬間に、突進用黒背景暗転を開始する。（ユーザー指定）
- 進行方向側の画面外へ到達した時点でStateDef `1204`へ移る。（ユーザー指定）

##### StateDef 1204：横断後の画面外移動

- StateDef `1201`の水平速度を維持し、停止せず画面外を移動し続ける。（ユーザー指定）
- 45tick経過時に速度を`0,0`へ停止し、StateDef `1202`へ移る。（ユーザー指定）

##### StateDef 1202：位置確定と復帰

- 現在の向きは変更しない。（ユーザー指定）
- 右向きの場合は左画面端から40px内側となる`ScreenPos X=40`へ位置を確定する。（ユーザー指定）
- 左向きの場合は右画面端から40px内側となる`ScreenPos X=280`へ位置を確定する。（ユーザー指定）
- StateDef `1204`終了時の高度を維持する。（ユーザー指定の動作から解決）
- 異形回避のStateDef `302`を直接共有せず、その復帰を複製した攻撃用StateDef `1202`とController内の突進専用復元モデルを使用する。（ユーザー指定、攻撃予約範囲の維持）
- 異形回避復帰の16tickに対し、突進復帰は約3分の1となる5tickで全身縦長復元を完了する。（ユーザー指定）
- 復帰完了後は操作可能なStateDef `0`へ戻る。（`common-v1`）

##### 状態間の共通条件

- StateDef `1200`〜`1204`では`ctrl=0`とする。（`common-v1`）
- StateDef `1200`〜`1204`の連続移動と位置確定は、通常の期限付き移動要求および技固有の排他処理と競合しないようにする。（TENKIKAI移動規約）
- 画面外移動中はカメラを追従させない。（ユーザー指定の画面外移動から解決）

#### 1-2. 飛び道具・衝撃波などの主表現

## 演出と攻撃定義の同期

### 発生時刻

StateDef `1200`と`1203`は攻撃判定を持たない退避・不在区間とする。StateDef `1201`へ進入して画面外から前方へ移動を開始する時点で攻撃判定を有効にする。突進用黒背景暗転は、StateDef `1201`進入時ではなくRoot原点が画面端を横切って画面内へ侵入した時点で開始する。

### 位置・範囲

攻撃判定はRoot本体へ設定し、画面外から反対側の画面外までRootとともに移動する。画面外にいる間の判定を含めるかは、Clsn1と画面外判定位置の確定時に同期させる。

### 持続・消滅

攻撃判定はStateDef `1201`の間だけ有効とし、StateDef `1204`へ移った時点で解除する。単発命中後も移動演出は中断せず、反対側の画面外まで継続する。背景暗転は開始から11tickで通常明度へ戻る。

### 命中時演出

命中音、Spark、画面振動および追加エフェクトは現時点で指定しない。

## 実装対応

### StateDef

- `1200`：後方画面外への退避
- `1201`：画面横断突進と攻撃判定
- `1202`：反対側画面端から40pxの位置確定と、突進専用の5tick復帰
- `1203`：突進前の30tick画面外不在
- `1204`：横断後の45tick画面外移動
- `1200`〜`1299`：本技の予約範囲

### Helper・Projectile・Explod

- 攻撃用Helper、ProjectileおよびExplodは使用しない。
- 突進用波紋Helper ID `500040`・`500041`を使用する。
- 突進用黒背景暗転Helper ID `504010`を使用し、背景色変更共通実行StateDef `504900`へ遷移させる。
- 横線形衝撃波Helper ID `505000`を使用し、横線形衝撃波共通実行StateDef `505900`へ遷移させる。

### 変数

- 入力にはRootの`var(2)` bit 4を使用する。
- 継続移動にはRootの既存移動要求変数を使用する。
- 本体自由傾斜には`the_controller`の既存自由傾斜変数を使用する。
- 突進復帰は`the_controller`の本体アニメーション変更・時間付き処理予約へ`5tick / type 2`を登録し、専用変数を追加しない。

### State Controller

- StateDef `-1`：通常時の`X`遷移先をStateDef `4001`から`1200`へ変更する。
- StateDef `1200`・`1201`・`1204`：速度制御と遷移条件を担当する。
- StateDef `1201`：`HitDef`、突進波紋生成、Root原点の画面侵入判定、突進用黒背景暗転Helper生成および横線形衝撃波Helper生成を担当する。
- StateDef `1203`：30tickの画面外不在を担当する。
- StateDef `1202`：`PosAdd`による画面端補正と操作可能状態への復帰を担当する。
- `the_controller`：StateDef `1200`〜`1204`を監視し、本体自由傾斜、Head位置、Aura同期、Rootの画面外移動許可、および異形回避復帰から分離した5tickの突進専用復元を管理する。

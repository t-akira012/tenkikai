# 001: 画面横断突進

## 基本情報

- 状態：実装済み・実機確認中
- StateDef：`1200`〜`1204`
- 予約範囲：`1200`〜`1299`
- 入力：`236+A`（`D,DF,F,a`）または`26+A`（`D,F,a`）。Command受付30tick、入力bit 14・マスク値`16384`
- 技分類：突進
- 使用デフォルト：`common-v1`、`rush-v1`

## ユーザー要求

通常時の`X`オーラバウンド確認を新規の突進技へ置き換える。既存の`X`処理は確認用途だけであるため、上書きしてよい。異形回避中の`X`による出現位置選択は維持する。

発動すると、現在位置から現在の向きに対する後方の画面外へ、本体自由傾斜を使用した後方ダッシュで移動する。開始位置にかかわらず、後方画面外へは5tick以内に到達する。

後方画面外へ到達した後は30tick不在となる。その後、本体自由傾斜によってほぼ横倒しになり、通常の前方ダッシュの2.5倍の速度で前方へ突進する。後方画面外から画面全体を横断し、進行方向側の反対画面外まで抜ける。

Root原点が画面内へ侵入した瞬間に、背景だけを黒く暗転する。3tickで暗くなり、通常明度の25%となるピークを5tick維持し、3tickで通常明度へ戻る。

同じ画面侵入時に、突進開始高度を中心として画面を横断する横線形衝撃波を発生させる。細い横線を上下対称へ拡大し、消滅時は徐々に透明にする。

反対側の画面外へ抜けた後も45tickは同じ方向へ移動を続け、45tick経過時に停止して復帰する。

横断後は、現在の向きと反対側にある画面端から40px内側へ位置を確定し、異形回避の復帰を複製した突進専用の5tick復帰によって通常状態へ戻る。異形回避復帰と突進復帰は概念的に異なるため倍率計算を分離し、時間管理だけを本体アニメーション変更・時間付き処理予約として共通化する。

現行の横方向突進を、向いている正面を基準とする角度`0`度のパターンとして扱い、突進本体、線形衝撃波、楕円波紋、本体傾斜および速度を同じ角度から計算できる360度共通モデルへ変更する。技で使用する方向は事前定義したパターンに限定し、パターン間ではStateDefと処理経路を複製せず、角度、開始位置、速度・加速度およびエフェクト位置の変数値だけを変更する。

発動コマンドを`236+A`または`26+A`とし、画面外待機の30tickに前・上・後入力による角度選択を受け付ける。前入力は`45`度、上入力は`90`度、後入力は`275`度とし、追加入力がなければ現在と同じ並行`0`度とする。初動コマンド末尾の前入力を選択入力と誤認しないよう、StateDef `1203`進入後に全方向入力が一度離れてから選択を受け付ける。方向入力は入力規約上の前・上・後とする。

現行のRoot軌道中心Y `170`と線形衝撃波中心Y `163`の差を維持し、エフェクトをRoot座標へ単純一致させない。攻撃判定は本体傾斜へ追従させず、画面軸に平行な固定正方形とする。TENKIKAIの高速移動と性能を優先し、表示より多少広い攻撃判定を許容する。

## 演出と攻撃定義の同期

### 発生時刻

StateDef `1200`と`1203`は攻撃判定を持たない退避・不在区間とする。StateDef `1201`へ進入して画面外から前方へ移動を開始する時点で攻撃判定を有効にする。突進用黒背景暗転は、StateDef `1201`進入時ではなくRootの前進座標がパターンの画面侵入前進座標へ初めて到達した時点で開始する。

### 位置・範囲

攻撃判定はRoot本体のAction `1201`へ設定し、画面軸に平行な正方形`-65,-65,65,65`が画面外から反対側の画面外までRootとともに移動する。本体とエフェクトだけを角度へ追従させ、Clsn1は回転させない。

### 持続・消滅

攻撃判定はStateDef `1201`の間だけ有効とし、StateDef `1204`へ移った時点で解除する。単発命中後も移動演出は中断せず、反対側の画面外まで継続する。背景暗転は開始から11tickで通常明度へ戻る。

### 命中時演出

命中音、Spark、画面振動および追加エフェクトは現時点で指定しない。

## 実装対応

### StateDef

- `1200`：後方画面外への退避
- `1201`：局所座標から求めた360度画面横断突進、回転エフェクト生成と固定正方形攻撃判定
- `1202`：終了時の法線座標を保持した復帰前進座標への位置確定、5tick復元予約、2tick後のStateDef `0`復帰
- `1203`：突進前の30tick画面外不在
- `1204`：横断後の45tick画面外移動
- `1200`〜`1299`：本技の予約範囲

### Helper・Projectile・Explod

- 攻撃用Helper、ProjectileおよびExplodは使用しない。
- 突進用波紋Helper ID `500040`・`500041`を使用する。
- 突進用黒背景暗転Helper ID `504010`を使用し、StateDef `504990`から非常駐Helper共通基盤へ接続する。
- 横線形衝撃波Helper ID `505000`を使用し、StateDef `505990`から非常駐Helper共通基盤へ接続する。

### 変数

- 発動入力はRootの`var(2)` bit 14（マスク`16384`）へ変換する`236+A`および`26+A`とする。
- Rootの`var(15)`を突進角度パターン番号に使用する。StateDef `1200`で`0`へ初期化し、StateDef `1203`の前・上・後入力で`1`・`2`・`3`へ変更する。
- Rootの`var(16)`を画面侵入時の暗転・線形衝撃波生成済みフラグに使用する。
- Rootの`var(17)`を分岐受付ラッチに使用する。StateDef `1203`進入後に方向入力が全て解除されたことを記録し、その後の単独方向入力だけを分岐に採用する。
- Rootの`fvar(10)`〜`fvar(23)`へ角度、速度、加速度、経路中心、開始・侵入・退出・復帰の局所座標、線形衝撃波と波紋の局所Offset、法線入力速度を保存する。
- Rootの`fvar(24)`〜`fvar(29)`を復帰時の法線座標、現在の前進座標、現在の法線入力速度、目標X・Y速度および加速度方向角へ使用する。
- 本体自由傾斜には`the_controller`の既存自由傾斜変数を使用する。
- 突進復帰は`the_controller`の本体アニメーション変更・時間付き処理予約へ`5tick / type 2`を登録し、専用変数を追加しない。

### State Controller

- StateDef `-1`：`236+A`・`26+A`の入力bit 14からStateDef `1200`へ遷移する。異形回避StateDef `300`中のX追加入力による出現位置選択は維持する。
- StateDef `1200`：パターン番号と共通計算へ渡す調整値を保存し、後方退避を担当する。
- StateDef `1201`・`1204`：角度から速度成分を計算し、パターンの加速度で目標速度へ近づける。
- StateDef `1201`：`HitDef`、前進座標による画面侵入・退出判定、回転した突進波紋生成、突進用黒背景暗転Helper生成および線形衝撃波Helper生成を担当する。
- StateDef `1203`：30tickの画面外不在と、方向入力が一度離れた後の角度分岐受付を担当する。
- StateDef `1202`：`PosAdd`によるパターン復帰位置補正と操作可能状態への復帰を担当する。
- `the_controller`：StateDef `1200`〜`1204`を監視し、角度`0`度の既存傾斜へパターン角度を合成した本体自由傾斜、Head位置、Aura同期、Rootの画面外移動許可、および異形回避復帰から分離した5tickの突進専用復元を管理する。

# StateDef -1/-2/-3 作業規則

StateDef `-1`、`-2`、`-3` は責務を分離して記述する。

## StateDef -1

プレイヤー入力・コマンドを起点とする状態遷移を記述する。

`command` トリガーによる `ChangeState` は原則として `-1` に置く。例えば、`holdfwd` や `holdback` を検知して空中歩行ステートへ遷移させる処理は `-1` の責務である。

## StateDef -2

相手キャラクターにState奪取されている場合も機能する、完全な常時監視を記述する。

`SelfState` による強制的な復帰、キャラクター固有時間、デバッグ表示など、State奪取中も維持する必要がある処理を置く。入力を起点とする通常の状態遷移は置かない。

## StateDef -3

相手キャラクターにState奪取されている場合は機能しない、低レベルの常時監視を記述する。

浮遊位置、重力、接地補正、StateTypeの同期など、通常の自キャラ状態でのみ実行する物理処理を置く。コマンド入力を直接の状態遷移条件として使用しない。

## 作業時の確認

新しい処理を追加する場合は、入力による遷移か、キャラクター固有の常時処理か、物理・状態同期の強制処理かを判定し、対応するStateDefへ配置する。

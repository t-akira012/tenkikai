# Rootアニメーション時間保持規約

## 適用範囲

Rootアニメーションの開始時点における`AnimTime`絶対値を、Helperの位置、角度、倍率、透過、演出時間などへ利用する処理に適用する。

設計判断の背景は[ADR 019: Rootアニメーション時間のController保持](ADR/019-controller-root-animtime.md)を参照する。

## 保持責務

Rootアニメーション番号と、アニメーション変更時の`abs(root,animtime)`は、常駐Helper `the_controller`が保持する。

頭部、オーラ、攻撃演出などの利用Helperは、同じRootアニメーション時間を自身の変数へ保存してはならない。固定した要素数、固定した要素時間、StateDefの`time`、Helper自身の`time`からRootアニメーション総時間を代用してはならない。

## 変数割り当て

- `the_controller`の`var(15)`：保存済みRootアニメーション番号
- `the_controller`の`var(16)`：アニメーション変更時の`abs(root,animtime)`

この割り当てを別用途へ変更または再利用してはならない。

## 更新条件と順序

`the_controller`はRootのアニメーション番号を毎tick監視する。保存済みアニメーション番号と`root,anim`が異なる場合、または保存済み時間が未初期化の場合に更新する。

同一Controller処理内では、次の順序を維持する。

1. `var(16)`へ`abs(root,animtime)`を保存する。
2. `var(15)`へ`root,anim`を保存する。

アニメーション番号を先に更新してはならない。利用Helperが、新しいアニメーション番号と古い時間値の組み合わせを有効な情報として読む可能性があるためである。

## 利用条件

利用Helperは、次の条件をすべて満たす場合だけ保存済み時間を使用する。

- `helper(99004),var(15)=root,anim`
- `helper(99004),var(16)>0`

条件を満たさない場合は、保存済み時間を使用した位置、角度、倍率、透過などの計算を実行しない。利用Helper側で推測値や固定値へフォールバックしてはならない。

## アニメーション定義変更への追従

利用側の計算は`helper(99004),var(16)`を全体時間として組み立てる。AIR側の要素数や各要素の表示時間をCNSへ重複記載してはならない。

`AnimTime`は再生中に非正で終了時に`0`となるため、保存時に`abs`を適用して正の全体時間として扱う。進行計算では、現在の`root,animtime`と保存値を組み合わせる。

# フィボナッチ・ライトHelper変数

StateDef `502000`・`502010`が用途別の全設定値を保存し、StateDef `502900`が同じ変数契約で共通実行する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 粒子生成番号 |
| `var(1)` | 生成番号の1粒子あたり増分 |
| `var(2)` | 同一tick生成数 |
| `var(3)` | 粒子寿命 |
| `var(4)` | Helper寿命 |
| `var(5)` | 同一tick生成カウンター |
| `var(6)` | Helper経過tick |
| `var(7)`、`var(8)` | 粒子ActionとExplod ID |
| `var(9)` | 描画優先順位 |
| `var(10)` | Bind時間 |
| `var(11)` | 最前面表示フラグ |
| `var(12)` | 独自パレットフラグ |
| `var(13)` | 親Helper追従フラグ |
| `var(14)` | 減算合成フラグ |
| `var(15)` | `k`揺動の初期位相用擬似乱数値 |
| `var(16)` | `k`揺動周期 |
| `var(17)`〜`var(19)` | 初期位相用LCGの法、乗数および加算値 |
| `var(20)` | Explod化する論理サンプルの間引き数 |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | 現在の黄金角係数`k` |
| `fvar(1)` | 現在粒子の角度 |
| `fvar(2)`、`fvar(3)` | 現在粒子のX・Y座標計算値 |
| `fvar(4)` | 生成位置倍率 |
| `fvar(5)` | 表示倍率 |
| `fvar(6)` | 速度倍率 |
| `fvar(7)` | 加速度倍率 |
| `fvar(8)` | 黄金角係数`k`の基準値 |
| `fvar(9)` | `k`の基準値に対する揺動率 |
| `fvar(10)` | `k`揺動の初期位相 |

# フィボナッチ・ライトHelper変数

StateDef `502000`が全設定値を保存し、StateDef `502900`が同じ変数契約で共通実行する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 粒子生成番号 |
| `var(1)` | 生成番号の1粒子あたり増分 |
| `var(2)` | 同一tick生成数 |
| `var(3)` | 粒子寿命 |
| `var(4)` | Helper寿命 |
| `var(5)` | 同一tick生成カウンター |
| `var(6)` | Helper経過tick |
| `var(7)`、`var(8)` | 粒子ActionとExplod ID |
| `var(9)` | 描画優先順位 |
| `var(10)` | Bind時間 |
| `var(11)` | 最前面表示フラグ |
| `var(12)` | 独自パレットフラグ |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | 黄金角係数`k` |
| `fvar(1)` | 現在粒子の角度 |
| `fvar(2)`、`fvar(3)` | 現在粒子のX・Y座標計算値 |
| `fvar(4)` | 生成位置倍率 |
| `fvar(5)` | 表示倍率 |
| `fvar(6)` | 速度倍率 |
| `fvar(7)` | 加速度倍率 |

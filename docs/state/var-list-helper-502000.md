# フィボナッチ・ライトHelper変数

StateDef `502000`〜`502999`を使用するHelperは同じ変数契約を使用する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 粒子生成番号 |
| `var(1)` | 生成番号の1粒子あたり増分 |
| `var(2)` | 同一tick生成数 |
| `var(3)` | 粒子寿命 |
| `var(4)` | Helper寿命 |
| `var(5)` | 同一tick生成カウンター |
| `var(6)` | Helper経過tick |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | 黄金角係数`k` |
| `fvar(1)` | 現在粒子の角度 |
| `fvar(2)` | 現在粒子のX座標計算値 |
| `fvar(3)` | 現在粒子のY座標計算値 |

# 三次元巡回移動Helper変数

三次元巡回移動責務を持つHelperへ適用する。表示素材や攻撃判定を問わず同じ割当を使用し、他責務の変数領域と重ねない。

| 変数 | 用途 |
| --- | --- |
| `var(10)` | 位相番号。両手光弾では`0`〜`5` |
| `var(11)` | 完成半径までの時間。両手光弾では`12tick` |
| `var(12)` | 一周時間。両手光弾では`120tick` |
| `var(13)`、`var(14)` | 奥側・手前側の描画優先順位。両手光弾では`-1`・`1` |
| `var(15)`、`var(16)` | Root基準中心X・Y Offset。両手光弾では`0,-55` |
| `var(17)` | 生成元Helperの生成時共通経過tick |
| `var(18)` | 分岐選択。`1`はA、`2`はB、`3`はC。発出管理Helperが存在する間は同Helperの確定値を毎tickコピーする |
| `var(19)` | Bの慣性射出開始済みフラグ |
| `var(50)` | A/B/C選択時刻。発出開始基準の共通経過tick、未選択は`-1` |
| `var(51)` | Bの加速時間`110tick` |
| `var(52)`〜`var(54)` | Cの拡大・最大維持・収縮時間。`30`・`45`・`15tick` |
| `var(55)` | Aの発出開始基準終了時刻`60tick` |
| `var(56)` | B入力から安全上限までの時間`180tick` |
| `var(57)` | Bの画面外終了余白`80px` |
| `fvar(6)`、`fvar(7)` | 楕円のX・Y半径。両手光弾では`60,20` |
| `fvar(8)` | 時間差生成を補正した初期角度 |
| `fvar(9)` | 現在角度 |
| `fvar(10)` | 現在の軌道展開率 |
| `fvar(11)`、`fvar(12)` | 基本角速度と現在角速度。基本は`3度/tick` |
| `fvar(13)`、`fvar(14)` | B・Cの目標角速度。`30`・`6度/tick` |
| `fvar(15)`、`fvar(20)` | 前tickの巡回相対X・Y座標 |
| `fvar(21)`、`fvar(22)` | 現在のX・Y半径 |
| `fvar(23)`、`fvar(24)` | Cの最大X・Y半径。`160,100` |
| `fvar(25)` | Bの外向き放射速度`12px/tick` |
| `fvar(26)`、`fvar(27)` | B射出後のX・Y移動量 |
| `fvar(28)`、`fvar(29)` | 現在の巡回相対X・Y座標 |
| `fvar(30)` | 加速または半径変化の現在補間率 |

## 共通ヘッダー

`sysvar`は[非常駐Helper共通変数](var-list-helper-transient-common.md)に従う。両手光弾では明光弾表示および攻撃判定と同じHelper上で併用する。

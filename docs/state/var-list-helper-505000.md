# 横線形衝撃波Helper変数

StateDef `505000`が用途別設定値を保存し、StateDef `505990`から共通基盤へ接続してStateDef `505900`が実行する。共通`sysvar`は[非常駐Helper共通変数](var-list-helper-transient-common.md)を参照する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 表示Action |
| `var(1)` | 最終実行tick |
| `var(2)` | 縦倍率の拡大時間 |
| `var(3)` | フェード開始tick |
| `var(4)` | フェード時間 |
| `var(5)`、`var(6)` | 開始・終了の前景α値 |
| `var(7)`、`var(8)` | 開始・終了の背景α値 |
| `var(9)` | 描画優先順位 |
| `var(12)` | 合成方式。`0`通常、`1`加算、`2`加算α、`3`減算 |
| `var(13)` | 倍率補間方式。`0`線形、`1`二次イーズアウト、`2`三次イーズアウト |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | X倍率 |
| `fvar(1)`、`fvar(2)` | Y倍率の開始値・終了値 |
| `fvar(3)` | 現在のY倍率 |
| `fvar(4)`、`fvar(5)` | 現在の前景α値・背景α値 |
| `fvar(6)` | 拡大補間の正規化経過率 |
| `fvar(7)`、`fvar(8)` | 親Rootの突進パターンから求めた画面固定X・Y座標 |
| `fvar(9)` | 親Rootの突進パターン角度を向きで鏡映した表示角度 |

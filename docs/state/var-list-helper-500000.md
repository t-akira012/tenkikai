# 楕円衝撃波Helper変数

Helper ID `500000`・`500001`・`500010`・`500011`は同じ変数契約を使用する。各Helperは独立した変数領域を持つ。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 進行方向。前方`1`、後方`-1` |
| `var(1)` | 寿命 |
| `var(2)` | 透明化開始tick |
| `var(3)` | 円弧側。左`0`、右`1` |
| `var(4)` | 描画優先順位 |
| `var(5)` | Projectile使用フラグ。ダッシュ用は`0` |
| `var(6)` | AfterImage残存時間 |
| `var(7)` | AfterImage最大枚数 |
| `var(8)` | AfterImage `timegap` |
| `var(9)` | AfterImage `framegap` |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | ダッシュと逆方向へ流れるX速度 |
| `fvar(1)` | 初期X倍率 |
| `fvar(2)` | 初期Y倍率 |
| `fvar(3)` | 終了X倍率 |
| `fvar(4)` | 終了Y倍率 |
| `fvar(5)` | 半コサイン補間の進行率 |
| `fvar(6)` | 現在のX倍率 |
| `fvar(7)` | 現在のY倍率 |
| `fvar(8)` | 初期不透明度 |
| `fvar(9)` | 終了不透明度 |
| `fvar(10)` | 現在の不透明度 |

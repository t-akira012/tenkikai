# 楕円衝撃波Helper変数

Helper ID `500000`・`500001`・`500010`・`500011`・`500020`・`500021`・`500030`・`500031`は同じ変数領域を使用する。各Helperは独立した変数領域を持ち、用途別初動StateDefと対応する共通管理StateDefが必要な領域だけを使用する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | X運動方向。正方向`1`、負方向`-1`。静止用途では`1` |
| `var(1)` | 寿命 |
| `var(2)` | 透明化開始tick |
| `var(3)` | 円弧側。左`0`、右`1` |
| `var(4)` | 描画優先順位 |
| `var(5)` | Projectile使用フラグ。ダッシュ用は`0` |
| `var(6)` | AfterImage残存時間 |
| `var(7)` | AfterImage最大枚数 |
| `var(8)` | AfterImage `timegap` |
| `var(9)` | AfterImage `framegap` |
| `var(10)` | 惑星リングの角度再抽選周期 |
| `var(11)` | 擬似乱数の法および入力GameTimeの剰余範囲 |
| `var(12)` | LCG乗数 |
| `var(13)` | LCG加算値 |
| `var(14)` | 目標角度の最小値 |
| `var(15)` | 目標角度の値域 |
| `var(16)` | 現在の擬似乱数値 |
| `var(17)` | 惑星リングの基本回転角度 |
| `var(18)` | 惑星リングの回転方向。時計回り`1`、反時計回り`-1` |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | X速度。足元波紋では`0` |
| `fvar(1)` | 初期X倍率 |
| `fvar(2)` | 初期Y倍率 |
| `fvar(3)` | 終了X倍率 |
| `fvar(4)` | 終了Y倍率 |
| `fvar(5)` | 半コサイン補間の進行率 |
| `fvar(6)` | 現在のX倍率 |
| `fvar(7)` | 現在のY倍率 |
| `fvar(8)` | 初期不透明度 |
| `fvar(9)` | 終了不透明度 |
| `fvar(10)` | 現在の不透明度 |
| `fvar(11)` | 惑星リングの現在角度 |
| `fvar(12)` | 角度補間の開始角度 |
| `fvar(13)` | 角度補間の目標角度 |
| `fvar(14)` | 角度補間の進行率 |
| `fvar(15)` | 惑星リングの現在基本回転角度 |
| `fvar(16)` | 惑星リングのY倍率変動率 |

# 背景色変更Helper変数

StateDef `504000`、`504010`および将来の用途別出現StateDefが、暗転開始からピーク、ピーク維持、背景復帰の時間と各区間の色変更値を同じ変数契約で保存し、StateDef `504990`から共通基盤へ接続してStateDef `504900`で実行する。経過tick、責務bitmapおよび終了状態は[非常駐Helper共通変数](var-list-helper-transient-common.md)を使用する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(1)` | 寿命 |
| `var(2)` | 暗転開始からピークまでの時間 |
| `var(3)` | ピーク維持時間 |
| `var(4)` | 背景復帰時間 |
| `var(5)` | 一周期の時間 |
| `var(6)`〜`var(8)` | 開始時の乗算RGB |
| `var(9)`〜`var(11)` | ピーク時の乗算RGB |
| `var(12)`〜`var(14)` | 終了時の乗算RGB |
| `var(15)`〜`var(17)` | 開始時の加算RGB |
| `var(18)`〜`var(20)` | ピーク時の加算RGB |
| `var(21)`〜`var(23)` | 終了時の加算RGB |
| `var(24)` | 開始時の彩度 |
| `var(25)` | ピーク時の彩度 |
| `var(26)` | 終了時の彩度 |
| `var(27)` | 色反転フラグ |
| `var(28)` | `BgPalFX`適用時間 |

# 背景色変更Helper変数

StateDef `504000`が全設定値を保存し、StateDef `504900`が同じ変数契約で共通実行する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 経過tick |
| `var(1)` | 寿命 |
| `var(2)` | 色変化周期 |
| `var(3)`〜`var(5)` | 乗算RGB |
| `var(6)`〜`var(8)` | 加算RGB初期値 |
| `var(9)` | 1tickあたりの加算RGB減少量 |
| `var(10)` | 彩度 |
| `var(11)` | 色反転フラグ |
| `var(12)` | `BgPalFX`適用時間 |

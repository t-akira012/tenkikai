# 重力球Helper

StateDef `1100`の`private-time=12`で、Root前方45px・上方50pxへHelper ID `501000`として生成する。RootへBindせず、発出位置で停止・浮遊する。

## StateDef 501000: 初期化

浮遊位相、拡縮率、描画周期および総経過tickを無条件で初期化する。生成時のRoot位置を基準として前方45px・上方50pxへ自身の座標を確定し、同じtickにStateDef `501900`へ遷移する。複数の重力球は独立して存在し、確定後はRootへ追従しない。

## StateDef 501900: 共通出現

Helper本体はAction `18552`を加算表示する。Action `16000`のExplodを三層生成し、前面と背面へ減算合成、中央へ加算α合成を適用する。

Helper本体と三層Explodへ同じ半コサイン補間を適用し、12tickかけて倍率0から予定倍率まで拡大する。出現中も回転、拡縮、反転および浮遊を処理し、完了後にStateDef `501901`へ遷移する。

## StateDef 501901: 共通維持

前面と中央の層を毎tick不規則に水平・垂直反転する。Helper本体は60tick周期で回転と拡縮を繰り返し、48tick周期・振幅3pxで上下へ浮遊する。

移動速度は`0,0`で、生成から600tick経過またはラウンド終了時に消滅する。

青暗転、フィボナッチ・ライトおよび中心衝撃波は生成しない。

## 共通表示と防御

HelperはPlayerPush、被弾、画面追従および影を無効化し、`HitDef`を持たない。

使用変数は[重力球Helper変数](var-list-helper-501000.md)を参照する。

## 予約範囲

- 重力球専用StateDef：`501000`〜`501999`
- 汎用重力球Helper ID・StateDef：`501000`
- 共通出現StateDef：`501900`
- 共通維持StateDef：`501901`
- 前面暗色層Explod ID：`501010`
- 内部発光層Explod ID：`501011`
- 背面暗色層Explod ID：`501012`

# 重力球Helper

StateDef `1100`の`time=7`で、Root前方25px・上方70pxへHelper ID `501000`として生成する。RootがStateDef `1100`にいる間は同じ相対位置へ`BindToRoot`し、StateDef `1100`終了時にBindを解除して、その時点の位置で停止・浮遊する。

## StateDef 501000: 初期化

Action、出現時間、消滅時間、全寿命、三層倍率、中心収縮層、脈動、浮遊、回転、色、透明度、描画優先順位、Root追従位置、追従ラッチおよび惑星リング生成値をHelper自身の変数へ保存し、同じtickにStateDef `501900`へ遷移する。複数の重力球はそれぞれの生成時にだけ追従ラッチを有効化し、生成元RootがStateDef `1100`を終了した後は独立する。

## StateDef 501900: 共通実行

Helper本体はAction `18552`を加算表示する。Action `16000`のExplodを三層生成し、前面と背面へ減算合成、中央へ加算α合成を適用する。Action `16999`の中心収縮層Explodを上位へ重ね、外側から内側へ反復収縮させる。

追従ラッチが有効で、RootがStateDef `1100`にいる間は、保存された前方25px・上方70pxへ毎tick `BindToRoot`する。RootがStateDef `1100`を終了すると追従ラッチを無効化し、最後にBindされた位置から独立して浮遊する。無効化したラッチは再設定しないため、既存の重力球はRootが後からStateDef `1100`へ再進入しても追従しない。

保存された36tickの出現時間中は全表示層へ同じ半コサイン補間を適用し、倍率0から予定倍率まで拡大する。寿命末尾の36tickでは同じ補間を逆方向へ適用し、予定倍率から0へ縮小する。維持中は前面と中央の層を毎tick不規則に水平・垂直反転する。Helper本体は保存された周期と区間値で回転・拡縮し、本体浮遊波形の2倍の範囲で上下へ浮遊する。

維持区間中は48tick周期で惑星リングHelper `500030`・`500031`を現在位置へ一組生成する。惑星リングは親である重力球へBindし、独立した有限寿命で終了する。

形成完了後から消滅開始前までは48tick周期でフィボナッチ・ライトHelper `502010`を現在位置へ生成する。Helper寿命を生成周期と同じ48tickとして同時に一体だけ存在させ、重力球へ追従しながら収縮する光粒子群を展開する。最後に生成された粒子Explodは11tickの有限寿命で消滅演出の冒頭へ残る。描画優先順位は`12`とし、重力球本体と表層の間へ描画する。

移動速度は`0,0`で、生成から600tick経過またはラウンド終了時に消滅する。三層Explodの`removetime`もHelperの全寿命と同じ600tickとし、Helper消滅後へ残さない。

青暗転、全画面フィボナッチ・ライトおよび中心衝撃波は生成しない。

## 共通表示と防御

HelperはPlayerPush、被弾、画面追従および影を無効化し、`HitDef`を持たない。重力球を構成する惑星リングと内部フィボナッチ・ライトも影を表示しない。

使用変数は[重力球Helper変数](var-list-helper-501000.md)を参照する。

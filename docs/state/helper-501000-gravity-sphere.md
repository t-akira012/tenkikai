# 重力球Helper

StateDef `1100`の`private-time=12`で、Root前方45px・上方50pxへHelper ID `501000`として生成する。RootへBindせず、発出位置で停止・浮遊する。

## StateDef 501000: 初期化

Action、出現時間、消滅時間、全寿命、三層倍率、中心収縮層、脈動、浮遊、回転、色、透明度、描画優先順位および惑星リング生成値をHelper自身の変数へ保存し、同じtickにStateDef `501900`へ遷移する。複数の重力球は独立して存在し、生成後はRootへ追従しない。

## StateDef 501900: 共通実行

Helper本体はAction `18552`を加算表示する。Action `16000`のExplodを三層生成し、前面と背面へ減算合成、中央へ加算α合成を適用する。Action `16999`の中心収縮層Explodを上位へ重ね、外側から内側へ反復収縮させる。

保存された36tickの出現時間中は全表示層へ同じ半コサイン補間を適用し、倍率0から予定倍率まで拡大する。寿命末尾の36tickでは同じ補間を逆方向へ適用し、予定倍率から0へ縮小する。維持中は前面と中央の層を毎tick不規則に水平・垂直反転する。Helper本体は保存された周期と区間値で回転・拡縮し、本体浮遊波形の2倍の範囲で上下へ浮遊する。

維持区間中は48tick周期で惑星リングHelper `500030`・`500031`を現在位置へ一組生成する。惑星リングは親である重力球へBindし、独立した有限寿命で終了する。

移動速度は`0,0`で、生成から600tick経過またはラウンド終了時に消滅する。三層Explodの`removetime`もHelperの全寿命と同じ600tickとし、Helper消滅後へ残さない。

青暗転、フィボナッチ・ライトおよび中心衝撃波は生成しない。

## 共通表示と防御

HelperはPlayerPush、被弾および画面追従を無効化し、`HitDef`を持たない。重力球本体の影は表示する。

使用変数は[重力球Helper変数](var-list-helper-501000.md)を参照する。

## 予約範囲

- 重力球専用StateDef：`501000`〜`501999`
- 汎用重力球Helper ID・StateDef：`501000`
- 共通実行・寿命管理StateDef：`501900`
- 前面暗色層Explod ID：`501010`
- 内部発光層Explod ID：`501011`
- 背面暗色層Explod ID：`501012`
- 中心収縮層Explod ID：`501013`

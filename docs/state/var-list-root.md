# Root変数一覧

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | `private-gametime`。毎tick加算し、周期処理とAfterImage更新に使う |
| `var(1)` | 未使用 |
| `var(2)` | 自動運用フラグと共通入力ビットフィールド |
| `var(6)` | 異形回避の出現領域。`0`は未選択、`1`〜`3`は下段左中右、`4`〜`6`は上段左中右 |
| `var(7)` | 異形回避の追加入力受付。開始入力解除後だけ`1`にする |
| `var(8)` | 水平移動要求の`private-gametime`有効期限 |
| `var(9)` | 垂直移動要求の`private-gametime`有効期限 |
| `var(10)` | Root AfterImageの初回生成済みフラグ |
| `var(11)` | 水平軸の個別速度処理による排他期限 |
| `var(12)` | 垂直軸の個別速度処理による排他期限 |
| `var(13)` | 水平目標速度の最低速度保証モード。`1`で有効、通常は`0` |
| `var(14)` | 水平半コサイン減速の残りtick。開始速度の絶対値が`3`以下なら32、`3`超なら16から減算する |
| `var(15)` | 画面横断突進の角度パターン番号。`0`は入力なしの並行、`1`は`45`度、`2`は`270`度、`3`は`225`度 |
| `var(16)` | 画面横断突進の侵入時暗転・線形衝撃波生成済みフラグ |
| `var(17)` | 画面横断突進の分岐入力受付ラッチ。方向入力が一度すべて離された後に受付を有効化する |

### `var(2)` bit割当

| bit | 用途 |
| ---: | --- |
| 0〜16 | Command入力。個別割当は[入力ビットマップ](../AGENTS.input-map.md)を正本とする |
| 17 | 接地許可フラグ。StateDef `-3`がStateDef `1200`〜`1204`以外で立て、画面横断突進中は常に落とす |
| 18〜30 | 未使用 |
| 31 | 自動運用フラグ。マスク値`-2147483648` |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | `-1`から`1`を往復する浮遊表示位相 |
| `fvar(1)` | 水平移動要求の目標X速度 |
| `fvar(2)` | 水平移動要求のX加減速度 |
| `fvar(3)` | 垂直移動要求の目標Y速度 |
| `fvar(4)` | 垂直移動要求のY加減速度 |
| `fvar(5)` | 異形回避中の入力由来Y速度 |
| `fvar(6)` | 異形回避上昇曲線の正規化経過時間 |
| `fvar(7)` | 異形回避上昇曲線の正規化経過時間2乗 |
| `fvar(8)` | 異形回避上昇曲線のY速度成分 |
| `fvar(9)` | 水平半コサイン減速の開始X速度 |
| `fvar(10)` | 画面横断突進の進行角度。向いている正面を`0`度、画面下方向を正とする。StateDef `1203`の追加入力で`45`・`270`・`225`度へ設定する |
| `fvar(11)` | 画面横断突進の前進目標速度 |
| `fvar(12)` | 画面横断突進の加速度 |
| `fvar(13)`、`fvar(14)` | 画面横断突進の経路中心ScreenPos X・Y |
| `fvar(15)`、`fvar(16)` | 画面横断突進の開始前進座標・開始法線座標 |
| `fvar(17)` | 画面横断突進の画面侵入前進座標 |
| `fvar(18)` | 画面横断突進の退出前進座標 |
| `fvar(19)` | 画面横断突進の復帰前進座標 |
| `fvar(20)` | 画面横断突進の線形衝撃波法線Offset |
| `fvar(21)`、`fvar(22)` | 画面横断突進の波紋前進・法線Offset |
| `fvar(23)` | 画面横断突進の上下入力による法線速度の絶対値 |
| `fvar(25)` | 画面横断突進中の現在前進座標 |
| `fvar(26)` | 画面横断突進中の現在法線入力速度 |
| `fvar(27)`、`fvar(28)` | 画面横断突進の目標X・Y速度 |
| `fvar(29)` | 画面横断突進で現在速度から目標速度へ向かう加速度方向角 |

## システム変数

| 変数 | StateDef | 用途 |
| --- | --- | --- |
| `sysvar(0)` | `132`、`155`、`5081`、`5110` | 着地判定とダウン追撃後の接地済みフラグ |
| `sysvar(1)` | `5100`、`5110` | `floor(vel y)`を保持し、落下演出と効果音の選択に使う |
| `sysvar(2)` | `5080` | ダウン追撃Action `5080`・`5090`を選び、未定義時は`5030`へ戻す |

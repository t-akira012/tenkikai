# フィボナッチ・ライトHelper

## StateDef 502000: 基本黄金角パターン初期化

Helper ID `502000`の用途別出現StateDefである。Action、Explod ID、黄金角係数、生成番号と増分、同一tick生成数、生成位置倍率、表示倍率、速度、加速度、描画関係、粒子寿命およびHelper寿命をHelper自身の変数へ保存し、同じtickにStateDef `502990`へ遷移する。

## StateDef 502010: 重力球内部パターン初期化

重力球Helperが形成完了後に48tick周期で生成する用途別出現StateDefである。Action `18553`を使用し、黄金角係数`k`の基準値、揺動率、周期および生成時の擬似乱数位相を保存する。1tickごとに17個の論理サンプルを進め、5サンプルに1個だけをExplod化することで螺旋形状を保ったまま表示数を間引く。

Helper寿命は生成周期と同じ48tickとし、同時に一体だけ存在する。重力球Helperへ毎tick追従し、粒子を11tick表示する。最前面表示を無効化し、描画優先順位`12`で重力球内部へ描画する。全値を保存した同じtickにStateDef `502990`へ遷移する。

## StateDef 502020: 明光弾放出パターン初期化

明光弾Helperが生成から11tick後に一体生成する用途別出現StateDefである。Action `18553`を使用し、生成番号を1tickごとに`-3`ずつ進め、3サンプルに1個をExplod化する。粒子へ正方向の速度と加速度を与え、重力球内部パターンとは逆に光弾中心から外向きへ放出する。

親明光弾へ毎tick追従し、親の奥側・手前側描画優先順位を引き継ぐ。親明光弾のHelper IDが消滅した場合は終了要求を設定する。Helper寿命は生成時点の親明光弾残り時間と同期する。

## StateDef 502990: 共通基盤接続

責務マスク`4`、共通経過tick `0`、最終実行tick `var(4)-1`および初期化完了フラグを設定し、StateDef `599000`へ移る。

## StateDef 502900: 粒子生成・寿命管理

生成番号へ黄金角係数を乗じてAction `18553`の粒子位置を求める。揺動が有効な用途では、保存された基準値、割合、周期および初期位相から`k`を正弦波で変化させる。自己遷移によって用途別に保存された論理サンプル数を同一tickに計算し、保存された間引き数に該当する粒子だけを生成する。各粒子へ保存された初速度と加速度を与え、減算合成フラグが有効な用途では`trans=sub`を適用する。親追従が有効な用途ではHelper座標を親へ毎tick合わせる。親存在監視が有効な用途では親Helper IDがなくなった時点で終了要求を設定し、描画優先順位追従が有効な用途では親の巡回位相に応じた優先順位を使用する。処理後はStateDef `599040`へ進み、用途別寿命またはラウンド終了を共通寿命判定で処理する。

使用変数は[フィボナッチ・ライトHelper変数](var-list-helper-502000.md)を参照する。

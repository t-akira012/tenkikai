# ヘルパーステート

この文書は、`cns/observ.cns` と `cns/helper.cns` にある常時監視処理と頭部ヘルパーを説明する。

## 常時監視

### StateDef -2: 本体とヘルパーの毎tick処理

本体には `sin(gametime*0.08)*3` をY座標として設定し、周期的な上下動を与える。頭部ヘルパーID `99001` には本体のX座標と、本体より61ピクセル上を基準にした別周期の上下動を設定する。

本体と頭部ヘルパーの表示は `addalpha`、アルファ値 `256,55` にする。ヘルパーID `99001` 以外のヘルパーはStateDef `5150` へ送り、ヘルパー全般をStateDef `99000` へ誘導する処理も持つ。

### StateDef -3: 頭部生成と外観演出

本体に頭部ヘルパーID `99001` が存在しない場合、Action `99001` を使うプレイヤー型ヘルパー `the_head` を生成する。PauseとSuperPauseの間も非常に長い移動可能時間を与え、停止しにくくしている。

本体がStateDef `100～107` にいる間は、本体側を不可視にする。さらに本体と頭部へ加算合成の残像を設定し、初回と600tickごとに残像履歴を更新する。

残像コントローラー末尾の `ignorehitpase=1` は `ignorehitpause` の綴りではないため、ヒットポーズ無視指定としては機能しない可能性がある。

## 頭部ヘルパー

### StateDef 99000: ヘルパー振り分け

ヘルパーID `99001` であればStateDef `99001` へ移る。それ以外のヘルパーには、このStateDef内で追加動作を行わない。

### StateDef 99001: 頭部待機

Action `99001` を表示し続ける。向きが本体と異なる場合は反転し、本体と同じ向きを保つ。位置と透明度はStateDef `-2` 側で更新する。末尾の `null` コントローラーにより、このステートから自動では退出しない。

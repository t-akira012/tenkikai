# アタックステート

## 汎用両手光弾発出

### StateDef 1000: 発出姿勢と予備動作

両手光弾系統の共通初動ステート。`StateDef 1000`から`1099`までを、この系統の予約範囲とする。

開始時に速度をX方向、Y方向ともに`0`へ設定し、操作を受け付けない攻撃状態として、両手を広げた発出姿勢を60tick表示する。現時点では光弾、Helper、Explod、Projectile、HitDefを生成しない。

Action `1000`は仮素材としてSFF `1000,0`を60tick表示する。60tickの予備動作が終了すると、操作可能なStateDef `0`へ遷移する。

入力およびオートメーションからStateDef `1000`へ入る遷移は未実装である。将来、この共通初動から複数パターンの光弾系ステートへ分岐する。

## 汎用片手光弾発出

### StateDef 1100: 発出姿勢と予備動作

片手光弾系統の共通初動ステート。`StateDef 1100`から`1199`までを、この系統の予約範囲とする。

開始時に速度をX方向、Y方向ともに`0`へ設定し、操作を受け付けない攻撃状態として、片手で光弾を発出する姿勢を60tick表示する。現時点では光弾、Helper、Explod、Projectile、HitDefを生成せず、暗転も行わない。

Action `1100`は仮素材としてSFF `1100,0`を60tick表示する。60tickの予備動作が終了すると、操作可能なStateDef `0`へ遷移する。

Bボタン入力、または同じ入力ビットを立てるオートメーションによりStateDef `1100`へ遷移する。将来、この共通初動から複数パターンの片手光弾系ステートへ分岐する。

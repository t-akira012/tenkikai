# デフォルトステート

この文書は、`cns/command.cmd` と `cns/state.cns` にあるTENKIKAI固有の移動、登場、勝利を説明する。WinMUGENの共有ステートは[stcommon共有ステート](stcommon.md)を参照する。

## 入力によるステート遷移

### StateDef -1: 入力によるステート遷移

#### 入力ビット変換

毎tick、入力ビットフィールド`var(2)`の自動運用フラグであるビット31を維持し、下位の入力ビットを解除する。自動運用フラグが立っていない場合だけ、成立している全Commandを対応するビットへ変換する。Var番号、ビット位置、マスク値は[入力ビットマップ](../AGENTS.input-map.md)に従う。ビット変換処理は、入力ビットを参照するすべての`ChangeState`より前に実行する。

#### 移動ステートへの遷移

変換後の入力ビットを判定し、`X+Y`で異形回避、前方向2回入力で前方ダッシュ、後ろ方向2回入力で後方ダッシュへ移る。空中で前方向を入力するとStateDef `60`、後ろ方向を入力するとStateDef `61`へ移る。攻撃、投げ、必殺技、超必殺技、挑発への入力遷移は定義しない。

#### 上下入力状態

StateDef `-3`は、`var(2)`の上方向ビットと下方向ビットを参照し、上下の浮遊移動と`stand`・`crunch`・`air`の状態変更を行う。

## テスト用オーラバウンド

### StateDef 4001: オーラバウンド確認

X入力から遷移し、3tick後にStateDef `0`へ戻る。`the_controller` がRootのStateDefとprivate-timeを監視するためのテスト用StateDefである。

### StateDef 4002: オーラバウンド保持確認

Y入力から遷移し、3tick後にStateDef `0`へ戻る。4001より長く拡張を保持し、速く縮小する設定を確認する。

### StateDef 4003: オーラバウンド倍率確認

Z入力から遷移し、3tick後にStateDef `0`へ戻る。通常オーラの2.5倍の拡張量を確認する。

## 空中歩行

### StateDef 60: 空中前歩き

`StateType=A`、`MoveType=I`、`Physics=N`、`Ctrl=1` とし、水平速度を毎tick `0` にする。前方向入力中はX座標へ低速の位置加算を行いAction `20`を表示する。前後どちらも入力していない場合はAction `0`、後ろ方向へ切り替えた場合はStateDef `61`へ移る。`Pos Y>=0`でStateDef `0`へ戻り、操作を可能にする。

### StateDef 61: 空中後ろ歩き

`StateType=A`、`MoveType=I`、`Physics=N`、`Ctrl=1` とし、水平速度を毎tick `0` にする。後ろ方向入力中はX座標へ低速の位置加算を行いAction `21`を表示する。前後どちらも入力していない場合はAction `0`、前方向へ切り替えた場合はStateDef `60`へ移る。`Pos Y>=0`でStateDef `0`へ戻り、操作を可能にする。

## 前方近距離ワープ

前方向へ移動中に`X`を入力すると開始する。表示変形、短距離の瞬間移動、不可視時間、終了モーションで構成される。

### StateDef 100: 前方近距離ワープ開始

Action `100` を再生し、序盤から中盤にかけて横方向の表示倍率を変化させる。アニメーション終了時にX座標へ100を加え、StateDef `102` へ移る。

### StateDef 102: 前方ダッシュ不可視待機

キャラクターを不可視にしたまま10tick待機し、StateDef `101` へ移る。

### StateDef 101: 前方ダッシュ終了

Action `101` を再生する。アニメーション終了時にStateDef `0` へ戻り、操作を可能にする。

## 後方近距離ワープ

後ろ方向へ移動中に`X`を入力すると開始する。前方近距離ワープと同様、短距離の瞬間移動と不可視時間を使う。

### StateDef 105: 後方近距離ワープ開始

Action `105` を再生し、終了時にX座標へ-100を加えてStateDef `107` へ移る。

### StateDef 107: 後方ダッシュ不可視待機

キャラクターを不可視にしたまま10tick待機し、StateDef `106` へ移る。

### StateDef 106: 後方近距離ワープ終了

Action `106` を再生する。アニメーション終了時にStateDef `0` へ戻り、操作を可能にする。

## 高速ダッシュ

### StateDef 110: 前方高速ダッシュ

前方向を2回入力して開始し、前方向入力を続けている間だけ高速に位置加算する。歩行Actionを進行方向へわずかに傾け、入力解除でStateDef `0`へ戻る。後ろ方向入力でStateDef `111`へ移る。

### StateDef 111: 後方高速ダッシュ

後ろ方向を2回入力して開始し、後ろ方向入力を続けている間だけ高速に位置加算する。歩行Actionを進行方向へわずかに傾け、入力解除でStateDef `0`へ戻る。前方向入力でStateDef `110`へ移る。

## 異形回避

`X+Y`の同時入力で開始する。異形の回転、非表示の空間移動、別領域への再出現で構成される。

### StateDef 300: 回転と出現領域選択

Action `300`を再生する。HeadとHead Auraを同じ角度で回転させる。BodyとBody Auraの角度は`0`を維持し、アニメーション要素5の開始以降、要素数や各要素時間を固定せずに残り時間から進捗率を求め、余弦曲線によって後半ほど速く縮小して終了時にX・Y倍率を5%とする。縮小に伴ってSprite axisへ近づくBody中心を維持するため、通常の浮遊Offsetへ`-48*(1-Y倍率)`を加え、BodyとBody Auraを同じ量だけ上方向へ補正する。Aura Boundが有効な場合はBoundを優先する。回転中は前入力だけの場合に前方へ`6px/frame`、後入力時は後方へ`4px/frame`、左右未入力時は後方へ`2px/frame`で移動する。StateDef `-3`の浮遊移動によって上下入力も受け付ける。

開始入力の`X+Y`が出現領域として扱われないように、六ボタンを一度すべて解除してから追加入力を受け付ける。`X`、`Y`、`Z`は下段の左・中央・右、`A`、`B`、`C`は上段の左・中央・右として`var(6)`へ保存する。Action終了時にStateDef `301`へ移る。

### StateDef 301: 非表示と空間移動

Action `301`の非表示Spriteを使用し、8tickの間、画面から消失する。Rootと各Helperの残像も消去する。

選択列は画面上のX座標を3分割した位置へ合わせる。左列は`ScreenPos X=53`、中央列は`160`、右列は`267`を試験値とする。選択段はY座標で分け、下段を`Pos Y=-60`、上段を`Pos Y=-180`とする。

出現領域が未選択の場合は、相手の向きに対して25px背後となるX座標へ移動し、Y座標は現在高度を維持する。算出した`ScreenPos X`が0未満なら反対側の`300`、320を超えるなら反対側の`20`へ移動する。待機終了時にStateDef `302`へ移る。

### StateDef 302: 再出現

Action `0`へ戻して全身を再表示し、残像の初回生成フラグを解除する。1tick後にStateDef `0`へ戻り、操作を可能にする。

StateDef `300`〜`302`の間は、`the_controller`がPlayerPushとHelper Armorの攻撃受付を無効にする。

## 勝利

### StateDef 180: 勝利ステート決定

開始直後にStateDef `181` へ移る。勝利演出の入口として機能する。

### StateDef 181: 勝利ポーズ

Action `181` を再生し、全属性の攻撃を常時無効化する。別ステートへの自動遷移は定義せず、ラウンド終了処理に任せる。

## 登場

### StateDef 191: 登場

WinMUGEN共有のStateDef `190` から移行する。Action `190` を再生し、`Intro` フラグを維持する。

ラウンド開始後にAction `191` とAction `192` のExplodを生成し、Action要素7で共通効果音を2種類再生する。登場アニメーション終了時にStateDef `0` へ戻る。

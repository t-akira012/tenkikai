# デフォルトステート

`cns/command.cmd`と`cns/state.cns`にあるTENKIKAI固有ステートを記録する。共有ステートは[stcommon共有ステート](stcommon.md)を参照する。

## 入力によるステート遷移

### StateDef -1: 入力ビット変換と遷移

`var(2)`の自動運用フラグを維持して下位ビットを毎tick解除し、通常操作時だけ成立中のCommandを[入力ビットマップ](../AGENTS.input-map.md)へ変換する。変換後のビットから異形回避、前後ダッシュ、空中前後歩きへ遷移する。攻撃、投げ、必殺技、超必殺技、挑発への入力遷移は定義しない。上下移動と状態変更はStateDef `-3`が同じ入力ビットを読む。

## 固有ステート

| StateDef | 機能 |
| --- | --- |
| `4001` | X入力用オーラバウンド確認。3tick後に`0`へ戻る |
| `4002` | Y入力用の長時間保持・高速縮小確認。3tick後に`0`へ戻る |
| `4003` | Z入力用の通常比2.5倍確認。3tick後に`0`へ戻る |
| `60` | 空中前歩き。前入力中に低速移動し、後入力で`61`、接地で`0`へ移る |
| `61` | 空中後ろ歩き。後入力中に低速移動し、前入力で`60`、接地で`0`へ移る |
| `100`→`102`→`101` | 前方近距離ワープ。X座標を`+100`、10tick非表示後に終了Actionを経て`0`へ戻る |
| `105`→`107`→`106` | 後方近距離ワープ。X座標を`-100`、10tick非表示後に終了Actionを経て`0`へ戻る |
| `110` | 前方高速ダッシュ。前入力中だけ継続し、後入力で`111`、解除で`0`へ移る |
| `111` | 後方高速ダッシュ。後入力中だけ継続し、前入力で`110`、解除で`0`へ移る |
| `180` | 勝利演出入口。直ちに`181`へ移る |
| `181` | 勝利Actionと常時無敵を維持する |
| `191` | 登場Action、Explod、効果音を再生し、終了時に`0`へ戻る |

## 異形回避

| StateDef | 機能 |
| --- | --- |
| `300` | Action `300`でHead系を回転し、Body系を要素5以降に余弦曲線で5%まで縮小する。排他的な水平移動処理で前入力`6px/frame`、後入力`4px/frame`、左右未入力`2px/frame`を適用し、6次曲線で合計12px上昇する。六ボタンの再入力を`var(6)`へ保存する |
| `301` | 8tick非表示にして選択位置へ移動する。列の`ScreenPos X`は`53`、`160`、`267`、段の`Pos Y`は`-60`、`-180`。未選択時は相手の50px背後へ移り、画面外では反対端の`20`または`300`へ回り込む |
| `302` | Action `0`と残像を再開し、`private-time=0`で全身の16tick縦長復元を開始して、2frame後に操作可能なStateDef `0`へ戻る。変形はStateDef `302`終了後もControllerの持続カウンターで継続する |

StateDef `300`〜`302`ではPlayerPushとHelper Armorの攻撃受付を無効化する。変換と位置補正の詳細は[異形回避設計](../design/006-alien-rotation-evasion.md)を参照する。

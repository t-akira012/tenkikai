# デフォルトステート

`cns/command.cmd`と`cns/state.cns`にあるTENKIKAI固有ステートを記録する。共有ステートは[stcommon共有ステート](stcommon.md)を参照する。

## 入力によるステート遷移

### StateDef -1: 入力ビット変換と遷移

`var(2)`の自動運用フラグを維持して下位ビットを毎tick解除し、通常操作時だけ成立中のCommandを[入力ビットマップ](../AGENTS.input-map.md)へ変換する。変換後のビットから異形回避、前後ダッシュ、空中前後歩きへ遷移する。攻撃、投げ、必殺技、超必殺技、挑発への入力遷移は定義しない。上下移動と状態変更はStateDef `-3`が同じ入力ビットを読む。

## 固有ステート

| StateDef | 機能 |
| --- | --- |
| `4001` | X入力用オーラバウンド確認。3tick後に`0`へ戻る |
| `4002` | Y入力用の長時間保持・高速縮小確認。3tick後に`0`へ戻る |
| `4003` | Z入力用の通常比2.5倍確認。3tick後に`0`へ戻る |
| `60` | 空中前歩き。前入力中は目標X速度`3`へ`0.5/tick`で加速し、後入力で`61`、入力解除で慣性を保って`0`へ移る |
| `61` | 空中後ろ歩き。後入力中は目標X速度`-2`へ`1/3tick`で加速し、前入力で`60`、入力解除で慣性を保って`0`へ移る |
| `100`→`102/107`→`101/106` | `C`入力による前方近距離ワープ。前入力、または左右入力なしで前方への水平速度がある場合に開始する。予備Action中はPlayerPushを無効にし、X速度`1`へ`0.166667/tick`で収束する。瞬間移動時に速度と移動要求を0へ戻し、現在位置から遠い壁の5px手前へ移る。中央へ背を向けていた場合は非表示State `107`でTurnし、後方出現State `106`を使用する。それ以外は`102`から前方出現State `101`へ移る |
| `105`→`102/107`→`101/106` | `C`入力による後方近距離ワープ。後入力、または左右入力なしで後方への水平速度がある場合に開始する。予備Action中はPlayerPushを無効にし、X速度`-1`へ`0.166667/tick`で収束する。瞬間移動時に速度と移動要求を0へ戻し、現在位置から遠い壁の5px手前へ移る。中央へ背を向けていた場合は非表示State `102`でTurnし、前方出現State `101`を使用する。それ以外は`107`から後方出現State `106`へ移る |
| `110` | 前方高速ダッシュ。開始時および`private-time`の8tick周期でダッシュ波紋Helper `500010`・`500011`を後方18px・上方45pxへ一組生成する。前入力中は目標X速度`12`へ`3/tick`で加速し、後入力で`111`、入力解除で慣性を保って`0`へ移る |
| `111` | 後方高速ダッシュ。開始時および`private-time`の8tick周期でダッシュ波紋Helper `500010`・`500011`を後方18px・上方45pxへ一組生成する。後入力中は目標X速度`-8`へ`2/tick`で加速し、前入力で`110`、入力解除で慣性を保って`0`へ移る |
| `180` | 勝利演出入口。直ちに`181`へ移る |
| `181` | 勝利Actionと常時無敵を維持する |
| `191` | 登場Action、Explod、効果音を再生し、終了時に`0`へ戻る |

## 異形回避

| StateDef | 機能 |
| --- | --- |
| `300` | Action `300`でHead系を回転し、Body系を要素5以降に余弦曲線で5%まで縮小する。水平要求は前`6`・後`-4`・左右未入力`-2`を4tickで目標速度へ移行する。垂直軸は排他処理で入力由来の慣性と6次曲線の上昇速度を合成し、六ボタンの再入力を`var(6)`へ保存する |
| `301` | 8tick非表示にして選択位置へ移動する。列の`ScreenPos X`は`53`、`160`、`267`、段の`Pos Y`は`-60`、`-90`。未選択時は相手の50px背後へ移り、画面外では反対端の`20`または`300`へ回り込む |
| `302` | Action `0`と残像を再開し、`private-time=0`で全身の16tick縦長復元を開始して、2frame後に操作可能なStateDef `0`へ戻る。変形はStateDef `302`終了後もControllerの持続カウンターで継続する |

StateDef `300`〜`302`ではPlayerPushとHelper Armorの攻撃受付を無効化する。変換と位置補正の詳細は[異形回避設計](../design/006-alien-rotation-evasion.md)を参照する。

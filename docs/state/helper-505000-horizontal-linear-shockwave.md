# 横線形衝撃波Helper

## StateDef 505000: 画面横断突進パターン初期化

RootのStateDef `1201`が画面外から画面内へ侵入したtickに、Helper ID `505000`として一度生成する。Action、寿命、縦拡大時間、フェード区間、α値、描画優先順位、画面固定位置、合成方式、補間方式および倍率をHelper変数へ保存し、同じtickにStateDef `505990`へ遷移する。

## StateDef 505990: 共通基盤接続

責務マスク`32`、共通経過tick `0`、最終実行tick `var(1)`および初期化完了フラグを設定し、StateDef `599000`へ移る。

## StateDef 505900: 位置固定・縦拡大・フェード

Action `505000`を表示し、毎tick画面座標X `160`、Y `163`へ位置を補正する。X倍率`30.0`を保ち、Y倍率を`0.02`から`6.4`へ22tickの二次イーズアウトで拡大する。

経過tick `0`・`1`は加算α`256,0`を維持し、経過tick `2`から20tickかけて`0,256`へ線形補間する。描画優先順位は`-5`とする。処理後はStateDef `599900`へ進み、経過tick `22`の責務処理後またはラウンド終了時に共通寿命判定で消滅する。

HelperはPlayerPush、被弾および影を無効化する。

## 予約範囲

- 専用StateDef：`505000`〜`505999`
- 画面横断突進Helper ID・用途別出現StateDef：`505000`
- 将来の用途別出現StateDef：`505010`から10刻み
- 共通基盤接続StateDef：`505990`
- 共通実行StateDef：`505900`

# 常時監視ステート

この文書は、`cns/observ.cns` にあるStateDef `-2` と `-3` の常時監視処理を説明する。

## 常時監視

### StateDef -2: 本体とヘルパーの毎tick処理

#### 変数更新とデバッグ表示

本体の変数更新とデバッグ表示を行う。時間基準には本体の `private-gametime` を使用する。

#### 頭部ヘルパー位置

頭部ヘルパーID `99001` には本体のX座標と、本体より61ピクセル上を基準にした上下動を設定する。

#### 表示とヘルパー振り分け

本体と頭部ヘルパーの表示は `addalpha`、アルファ値 `256,55` にする。ヘルパーID `99001` 以外のヘルパーはStateDef `5150` へ送り、ヘルパー全般をStateDef `99000` へ誘導する処理も持つ。

### StateDef -3: 浮遊移動・状態変更・頭部生成と外観演出

#### 浮遊移動と状態変更

本体は上方向入力中に歩行速度相当で上昇し、入力がない場合は重力加算で下降する。Y座標が画面上部から400ピクセル相当を超えた場合は、重力加算を追加して上昇を減速する。Y座標0では下方向入力に応じて `crunch` または `stand`、Y座標が0より上では `air` とする。

#### 頭部ヘルパー生成

本体に頭部ヘルパーID `99001` が存在しない場合、Action `99001` を使うプレイヤー型ヘルパー `the_head` を生成する。PauseとSuperPauseの間も非常に長い移動可能時間を与え、停止しにくくしている。

#### 不可視化

本体がStateDef `100～107` にいる間は、本体側を不可視にする。さらに本体と頭部へ加算合成の残像を設定し、初回と600tickごとに残像履歴を更新する。

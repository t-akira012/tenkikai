# 常時監視ステート

この文書は、`cns/observ.cns` にあるStateDef `-2` と `-3` の常時監視処理を説明する。

## 常時監視

### StateDef -2: 本体とヘルパーの毎tick処理

#### 自動運用フラグ 利用したい場合は trigger1=1 に指定

最初のControllerで、本体の入力ビットフィールド`var(2)`に自動運用フラグのビット31を設定する。`trigger1=0`のため常時有効化は無効であり、パレット番号`6`から`12`の場合だけ有効になる。Helperの変数は変更しない。

#### 変数更新とデバッグ表示

本体の変数更新とデバッグ表示を行う。時間基準には本体の `private-gametime` を使用する。

#### AngleDraw無効化時の残留傾斜解除

`var(5)`を毎tick falseへ戻し、AngleDrawを中立値へ設定する。傾斜を必要とするStateDefは自身の処理中に`var(5)=1`を設定するため、傾斜対象をダッシュStateDefに限定しない。入力ビット用に予約された変数は再利用しない。

### StateDef -3: 浮遊移動・状態変更・頭部生成と外観演出

#### 浮遊移動と状態変更

本体は上方向入力中に歩行速度相当で上昇し、空中で下方向を入力すると位置加算で下降する。入力がない場合は重力加算で下降する。重力加算は `Pos Y<-40` かつ下方向入力がない場合に適用し、浮遊下限を超えた時点でY速度を `0` にする。地面 `Y=0` まで下降させない。Y座標0では下方向入力に応じて `crunch` または `stand`、Y座標が0より上では `air` とする。空中歩行StateDef `60`、`61` は前後入力中だけ継続し、入力解除時にStateDef `0` へ戻る。

#### 浮遊表示

本体の `stand`、前歩き、後ろ歩き、空中前歩き、空中後ろ歩き、通常浮遊に対して、`private-gametime` を位相にした周期的な `Offset Y` を適用する。Rootの `Pos Y`、重力、接地、StateType、当たり判定は変更しない。被弾中など `MoveType=H` の状態と `crunch` には適用せず、対象外ではオフセットを初期位置へ戻す。

#### 頭部ヘルパー生成

本体に頭部ヘルパーID `99001` が存在しない場合、Action `99001` を使うプレイヤー型ヘルパー `the_head` を生成する。PauseとSuperPauseの間も非常に長い移動可能時間を与え、停止しにくくしている。

#### オーラヘルパー生成

本体にオーラHelper ID `99002` が存在しない場合、専用の常駐ステートへ移行するHelperを1体だけ生成する。

#### 本体残像

本体に加算合成の残像を設定し、初回と600tickごとに残像履歴を更新する。

# ヘルパー一覧

この文書は、TENKIKAIの定義ファイルにある `Helper` コントローラーを列挙する。StateDefとしてのヘルパーの挙動は[ヘルパーステート](helper.md)を参照する。

## 頭部ヘルパー

| 項目 | 定義 |
| --- | --- |
| 生成元 | `cns/observ.cns` のStateDef `-3` |
| 生成条件 | 本体であり、ID `99001` のヘルパーが存在しないとき |
| 名前 | `the_head` |
| ID | `99001` |
| 初期Action | `99001` |
| 種別 | `player` |
| Pause中の活動時間 | `99990000000` tick |
| SuperPause中の活動時間 | `99990000000` tick |

常時監視から本体に1体だけ生成される。生成後はStateDef `-2`によってStateDef `99000`へ移され、StateDef `99001000`で頭部表示として追従処理を行う。

## オーラヘルパー

| 項目 | 内容 |
| --- | --- |
| 生成条件 | 本体であり、ID `99002` のヘルパーが存在しないとき |
| 名前 | `the_aura` |
| ID | `99002` |
| 初期StateDef | `99002000` |

常時監視から本体に1体だけ生成される。専用StateDef `99002000`で本体の位置・向き・アニメーションへ追従し、鼓動する倍率、透過表示、AfterImageを適用する。

## `the_controller` Helper

| 項目 | 内容 |
| --- | --- |
| 生成条件 | 本体であり、ID `99004` のヘルパーが存在しないとき |
| 名前 | `the_controller` |
| ID | `99004` |
| 初期StateDef | `99004000` |

Rootの位置へ常時追従し、PlayerPushで相手を押し返す外殻としてHelper Armorを担う。相手の攻撃を受け、取得したダメージを本体へ渡しながら、RootのStateDefとprivate-timeを監視し、技ごとのオーラバウンド定義と進行も管理する。

## 頭部オーラヘルパー

| 項目 | 内容 |
| --- | --- |
| 生成条件 | 本体であり、ID `99003` のヘルパーが存在しないとき |
| 名前 | `the_head_aura` |
| ID | `99003` |
| 初期StateDef | `99003000` |

本体から1体だけ生成される。専用StateDef `99003000`で頭部Helperの位置・向き・アニメーション・描画オフセットへ追従し、鼓動する倍率、透過表示、AfterImageを適用する。

`Helper` コントローラーは4個、明示されたヘルパーIDは `99001`、`99002`、`99003`、`99004` の4種類である。

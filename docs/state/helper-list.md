# ヘルパー一覧

この文書は、TENKIKAIの定義ファイルにある `Helper` コントローラーを列挙する。StateDefとしてのヘルパーの挙動は[ヘルパーステート](helper.md)を参照する。

## 頭部ヘルパー

| 項目 | 定義 |
| --- | --- |
| 生成元 | `cns/observ.cns` のStateDef `-3` |
| 生成条件 | 本体であり、ID `99001` のヘルパーが存在しないとき |
| 名前 | `the_head` |
| ID | `99001` |
| 初期Action | `99001` |
| 種別 | `player` |
| Pause中の活動時間 | `99990000000` tick |
| SuperPause中の活動時間 | `99990000000` tick |

常時監視から本体に1体だけ生成される。生成後はStateDef `-2` によってStateDef `99000` へ移され、StateDef `99001` で頭部表示として待機する。本体のX座標と、本体より61ピクセル上を基準にした正弦波のY座標へ毎tick追従する。

## オーラヘルパー

| 項目 | 内容 |
| --- | --- |
| 生成条件 | 本体であり、ID `99002` のヘルパーが存在しないとき |
| 名前 | `the_aura` |
| ID | `99002` |
| 初期StateDef | `99002` |

常時監視から本体に1体だけ生成される。専用StateDef `99002` で本体の位置・向き・アニメーションへ追従し、鼓動する倍率、透過表示、AfterImageを適用する。

## 集計

`Helper` コントローラーは2個、明示されたヘルパーIDは `99001` と `99002` の2種類である。

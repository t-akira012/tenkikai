# 両手光弾発出管理Helper

## 初期化

### StateDef 509000: 発出設定の保存

StateDef `1000`の進入時にRootからHelper ID `509000`として生成される。生成間隔`6tick`、明光弾の安全上限`600tick`、自身の寿命`60tick`、明光弾入口StateDefおよび既定分岐Aを保存し、StateDef `509990`へ遷移する。

## 共通基盤接続

### StateDef 509990: 発出管理責務の開始

責務bitmapへ発出管理マスク`512`を設定する。共通経過tickを`0`、最終実行tickを`59`、初期化完了bitを有効にし、StateDef `599000`へ接続する。

## 明光弾生成

### StateDef 509900: 対向二個三組の生成

毎tick現在のRoot位置からY `-55px`へ追従する。RootがStateDef `1000`にいる間、変換済み入力bitを監視し、Aを`1`、Bを`2`、Cを`3`として分岐選択を更新する。ControllerはA、B、Cの順に実行するため、同一tickでは`C > B > A`となる。入力がないtickは直前の選択を保持する。

共通経過tick `0`で位相`0`・`3`、`6`で位相`1`・`4`、`12`で位相`2`・`5`の明光弾Helperを生成する。各組は180度離れ、全生成後は60度間隔となる。生成済みの各光弾は本Helperが存在する間、同じ分岐選択をコピーする。

発出管理Helper自身は不可視で、PlayerPush、被弾および影を無効化する。生成完了後も共通経過tick `59`まで存在し、分岐選択の伝播を継続してから共通寿命判定によって消滅する。生成済みの明光弾は選択確定後にParentへ依存せず、A・CではRootへ追従し、Bの射出後は独立移動する。

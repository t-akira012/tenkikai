# 三次元巡回移動Helper責務

## 三次元巡回移動

### StateDef 507900: Root周囲の楕円巡回

保存された初期角度へ現在角速度を毎tick加算する。生成から12tickは半コサイン補間で軌道半径を拡大し、その後はRootからX `0px`・Y `-55px`の中心を基準として、X半径`60px`・Y半径`20px`の楕円上へ配置する。

発出管理Helperが存在する間はA/B/C選択を毎tickコピーし、異なる時刻に生成された6個を発出開始基準の共通時刻へ合わせる。AとCの最終実行時刻は発出開始から299tick、Bは599tickになるよう、各光弾の生成時刻を差し引いて共通寿命を更新する。

Aは角速度と半径を維持する。Bは発出開始から120〜299tickの180tickで角速度を`3`から`30度/tick`へ半コサイン補間し、300tickで楕円拘束を解除する。解除時は現在と前tickの巡回相対座標差へ、現在角度の外向き`12px/tick`を加え、以後は完成したX・Y速度を現在座標へ加算する。射出後に画面の上下左右から80pxを越えた場合は終了要求を設定する。

Cは発出開始から120〜179tickに半径をX `60`・Y `20`からX `160`・Y `100`へ広げ、180〜269tickに最大半径を維持し、270〜299tickに元の半径へ戻す。角速度は拡大中に`3`から`6度/tick`へ上げ、その後は`6度/tick`を維持する。

角度の正弦が負となる画面上側では描画優先順位`-1`、正弦が0以上となる画面下側では`1`とする。Bの射出後は解除時の角度を保持する。Rootの向きは座標式へ使用せず、向きが変わっても画面座標上の回転方向を維持する。

座標と描画優先順位の完成後、同じtickの攻撃判定ルーターStateDef `599090`へ進む。

変数割当は[三次元巡回移動Helper変数](var-list-helper-507000.md)を参照する。

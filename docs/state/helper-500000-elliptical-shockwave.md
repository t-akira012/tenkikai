# 楕円衝撃波Helper

## StateDef 500000・500001: 小波紋初期化

実機確認済みの小波紋を初期化する。左円弧Helper ID `500000`と右円弧Helper ID `500001`を一組として使用し、AfterImageは時間`8`、最大枚数`6`とする。

## StateDef 500010・500011: ダッシュ波紋初期化

StateDef `110`・`111`の開始時と、その後`time`が8tick進むごとに、左円弧Helper ID `500010`と右円弧Helper ID `500011`を一組生成する。前方ダッシュではRoot後方6px、後方ダッシュでは逆側6pxに置き、どちらもRoot原点から上方45pxを中心とする。

小波紋と同じ形状、運動、拡大量および寿命を使い、AfterImageだけを時間`18`、最大枚数`12`へ増強する。

各初動StateDefはRootがStateDef `110`か`111`かを読み、進行方向、寿命、透明化開始、円弧側、描画優先順位、逆方向速度、初期・終了倍率、AfterImage設定をHelper自身の変数へ記録する。Projectile使用フラグは`0`であり、小波紋とダッシュ波紋は攻撃判定を生成しない。

全値を記録した同じtickにStateDef `500990`へ遷移し、楕円衝撃波責務bitを設定して非常駐Helper共通起点へ入る。

## StateDef 500020・500021: 足元波紋初期化

StateDef `-2`が地面隣接かつほぼ静止しているRootを24tick周期で検出し、左円弧Helper ID `500020`と右円弧Helper ID `500021`を一組生成する。生成位置は`postype=p1`の`pos=0,-pos y+26`とし、生成時のRoot直下にあるステージ地面へSprite軸補正を加えて固定する。

既存小波紋のX・Y倍率を入れ替えた横長形状とし、X速度`0`、寿命`20`tickでその場へ広がる。AfterImageは時間`8`、最大枚数`6`とする。Projectile使用フラグは`0`であり、攻撃判定を生成しない。

全値を記録した同じtickにStateDef `500990`へ遷移し、楕円衝撃波責務bitを設定して非常駐Helper共通起点へ入る。

## StateDef 500030・500031: 重力球惑星リング初期化

重力球HelperのStateDef `501900`が、維持区間中に左円弧Helper ID `500030`と右円弧Helper ID `500031`を一組生成する。生成位置はそのtickの重力球中心とし、生成後は`BindToParent time=1, pos=0,0`を毎tick適用して重力球へ追従する。

左右円弧は黒い減算合成と暗色AfterImageを使用し、左円弧を背面、右円弧を前面へ描画する。外側の横長楕円から内側の小さな楕円へ半コサイン補間で収縮する。

両Helperは同じ生成tick、再抽選周期、`GameTime`およびLCG式から同じ目標角度を算出する。開始角度、目標角度、補間経過を各Helper自身の変数へ保持し、兄弟HelperまたはRoot変数を参照しない。同じtickに左右ともStateDef `500990`へ遷移し、共通基盤からStateDef `500902`を実行する。

## StateDef 500040・500041: 突進波紋初期化

StateDef `1201`の開始時と、その後`time`が3tick進むごとに、左円弧Helper ID `500040`と右円弧Helper ID `500041`を一組生成する。生成位置はRootから局所前進`-6px`・局所法線`-45px`を突進パターン角度で回転して求める。

突進専用値として、寿命`13tick`、初期倍率X `0.05`・Y `0.19`、終了倍率X `0.8568`・Y `2.142`、AfterImage時間`54`・最大枚数`48`を保存する。逆方向速度、透明化開始および描画優先順位はダッシュ波紋と同じである。親Rootから突進パターン角度も保存し、共通寿命管理で逆方向速度と表示角度へ適用する。

全値を記録した同じtickにStateDef `500990`へ遷移し、楕円衝撃波責務bitを設定して非常駐Helper共通起点へ入る。

## StateDef 500990・500999: 共通基盤接続・用途振り分け

StateDef `500990`は責務マスク`1`、共通経過tick `0`、最終実行tick `var(1)`および初期化完了フラグを設定し、StateDef `599000`へ移る。StateDef `500999`は惑星リングを`500902`へ、それ以外を円弧側に応じて`500900`または`500901`へ振り分ける。

## StateDef 500900・500901: 共通寿命管理

二体は発生元から独立し、記録済みの自己変数だけで動作する。用途別の速度を保ち、初期倍率から終了倍率まで半コサイン曲線で拡大する。突進波紋では保存済みのパターン角度からX・Y速度を求め、表示角度を向きで鏡映する。その他の通常波紋は角度`0`度として従来のX方向運動を維持する。左円弧と右円弧は同じ座標・速度・倍率・透明化・寿命の式を使用し、用途ごとの描画優先順位だけを分ける。

生成直後にAfterImageを開始し、透明化開始tickまでは明瞭に表示する。その後は寿命終端へ向かって線形に透明化する。処理後はStateDef `599020`へ進み、共通寿命判定で終了する。Helper本体はPlayerPush、被弾、画面追従、影を持たない。

使用変数は[楕円衝撃波Helper変数](var-list-helper-500000.md)を参照する。

## StateDef 500902: 重力球惑星リング共通管理

記録済みの寿命、倍率、角度範囲、再抽選周期、LCG係数、AfterImageおよび描画優先順位だけを用いて、黒い惑星リングを実行する。倍率は外側から内側へ収縮する。寿命中に時計回りまたは反時計回りへ一回転する基本角度へ、周期ごとに`GameTime`から得た目標への半コサイン揺動角度を加える。

Y倍率は収縮中の基準倍率へ、寿命を一周期とする正弦波変動を重ねる。背面円弧は重力球各層の後ろへ、前面円弧は全レイヤーの前へ描画する。

左円弧と右円弧は同じ式を独立して実行し、描画優先順位だけを分ける。Helperは影を表示せず、PlayerPush、被弾および画面追従を無効化し、有限寿命またはラウンド終了で消滅する。

## 小波紋・ダッシュ波紋共通値

- 発生位置：進行方向後方`6` px、Root原点からY `-45` px
- 寿命：`18` tick
- 透明化開始：`4` tick
- 逆方向速度：`1.25` px/tick
- 初期倍率：X `0.10`、Y `0.38`
- 終了倍率：X `0.34`、Y `0.85`
- 倍率補間：半コサイン曲線
- 描画優先順位：奥側`-1`、手前側`10`
- 左円弧Action：`500000`、Sprite `10000,8`
- 右円弧Action：`500001`、Sprite `10000,9`
- Projectile：生成しない

## 重力球惑星リング値

- 寿命：48tick
- 角度再抽選周期：12tick
- 角度範囲：`-60`度〜`60`度
- 基本回転：寿命中に`360`度
- 回転方向：生成時の擬似乱数値から時計回りまたは反時計回りを選択
- LCG式：`(((GameTime % 65536) * 25173 + 13849) % 65536)`
- 初期倍率：X `0.90`、Y `0.175`
- 終了倍率：X `0.12`、Y `0.025`
- Y倍率変動：寿命を一周期とする正弦波、基準倍率の`±8%`
- 描画優先順位：背面`5`、前面`100`
- 合成：減算
- Projectile：生成しない

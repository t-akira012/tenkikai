# 楕円衝撃波Helper

## StateDef 500000・500001: 小波紋初期化

実機確認済みの小波紋を初期化する。左円弧Helper ID `500000`と右円弧Helper ID `500001`を一組として使用し、AfterImageは時間`8`、最大枚数`6`とする。

## StateDef 500010・500011: ダッシュ波紋初期化

StateDef `110`・`111`の開始時と、その後`private-time`が8tick進むごとに、左円弧Helper ID `500010`と右円弧Helper ID `500011`を一組生成する。前方ダッシュではRoot後方18px、後方ダッシュでは逆側18pxに置き、どちらもRoot原点から上方45pxを中心とする。

小波紋と同じ形状、運動、拡大量および寿命を使い、AfterImageだけを時間`18`、最大枚数`12`へ増強する。

各初動StateDefはRootがStateDef `110`か`111`かを読み、進行方向、寿命、透明化開始、円弧側、描画優先順位、逆方向速度、初期・終了倍率、AfterImage設定をHelper自身の変数へ記録する。Projectile使用フラグは`0`であり、小波紋とダッシュ波紋は攻撃判定を生成しない。

全値を記録した同じtickに、左円弧はStateDef `500900`、右円弧はStateDef `500901`へ遷移する。

## StateDef 500020・500021: 足元波紋初期化

StateDef `-2`が地面隣接かつほぼ静止しているRootを24tick周期で検出し、左円弧Helper ID `500020`と右円弧Helper ID `500021`を一組生成する。生成位置は`postype=p1`の`pos=0,-pos y+26`とし、生成時のRoot直下にあるステージ地面へSprite軸補正を加えて固定する。

既存小波紋のX・Y倍率を入れ替えた横長形状とし、X速度`0`、寿命`20`tickでその場へ広がる。AfterImageは時間`8`、最大枚数`6`とする。Projectile使用フラグは`0`であり、攻撃判定を生成しない。

全値を記録した同じtickに、左円弧はStateDef `500900`、右円弧はStateDef `500901`へ遷移する。

## StateDef 500900・500901: 共通寿命管理

二体は発生元から独立し、記録済みの自己変数だけで動作する。用途別のX速度を保ち、初期倍率から終了倍率まで半コサイン曲線で拡大する。左円弧と右円弧は同じ座標・速度・倍率・透明化・寿命の式を使用し、用途ごとの描画優先順位だけを分ける。

生成直後にAfterImageを開始し、透明化開始tickまでは明瞭に表示する。その後は寿命終端へ向かって線形に透明化する。Helper本体はPlayerPush、被弾、画面追従、影を持たず、寿命終了またはラウンド終了で消滅する。

使用変数は[楕円衝撃波Helper変数](var-list-helper-500000.md)を参照する。

## 小波紋・ダッシュ波紋共通値

- 発生位置：進行方向後方`18` px、Root原点からY `-45` px
- 寿命：`18` tick
- 透明化開始：`4` tick
- 逆方向速度：`1.25` px/tick
- 初期倍率：X `0.10`、Y `0.38`
- 終了倍率：X `0.34`、Y `0.85`
- 倍率補間：半コサイン曲線
- 描画優先順位：奥側`-1`、手前側`10`
- 左円弧Action：`500000`、Sprite `10000,8`
- 右円弧Action：`500001`、Sprite `10000,9`
- Projectile：生成しない

## 用途別値

| 用途 | Helper ID | 発生条件 | AfterImage時間 | 最大枚数 | `timegap` | `framegap` |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 小波紋 | `500000`・`500001` | 発生元が決定 | `8` | `6` | `1` | `1` |
| ダッシュ波紋 | `500010`・`500011` | StateDef `110`・`111`進入時と`private-time`の8tick周期 | `18` | `12` | `1` | `1` |
| 足元波紋 | `500020`・`500021` | `Pos Y>=-20`かつ`abs(Vel X)<1`で24tick周期 | `8` | `6` | `1` | `1` |

## 足元波紋値

- 発生位置：生成時のRoot直下にあるステージ地面からY `+26` px
- 寿命：`20` tick
- 透明化開始：`4` tick
- X速度：`0` px/tick
- 初期倍率：X `0.38`、Y `0.03`
- 終了倍率：X `0.85`、Y `0.10`
- 倍率補間：半コサイン曲線
- 描画優先順位：奥側の左円弧`-1`、手前側の右円弧`100`
- Projectile：生成しない

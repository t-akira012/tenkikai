# 非常駐Helper共通変数

StateDef `599000`〜`599999`の共通実行基盤を使用する全非常駐Helperへ適用する。各Helper個体は独立した変数領域を持つ。

## システム変数

| 変数 | 用途 |
| --- | --- |
| `sysvar(0)` | 責務bitmap。`1`楕円衝撃波、`2`重力球、`4`フィボナッチ・ライト、`8`中心衝撃波、`16`背景色変更、`32`横線形衝撃波 |
| `sysvar(1)` | 共通状態flags。bit 0・マスク`1`は初期化完了、bit 1・マスク`2`は終了要求 |
| `sysvar(2)` | Helper私有の共通経過tick。最初の責務周期は`0` |
| `sysvar(3)` | 最後に責務を実行する共通経過tick。アニメーション終了型は`-1` |
| `sysvar(4)` | 共通ヘッダー拡張用の予約領域。現在は`0` |

通常の`var`と`fvar`は各責務の変数文書に従う。同時に成立できる責務を追加する場合は、責務間で通常変数領域を競合させない。

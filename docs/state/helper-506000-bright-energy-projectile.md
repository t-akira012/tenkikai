# 明光弾Helper

## 位相別入口

### StateDef 506000〜506005: 両手光弾の位相保存

Helper IDと同じStateDefへ生成され、`0`〜`5`の位相番号を`var(10)`へ保存してStateDef `506100`へ遷移する。各入口はAction `506000`を使用する。

## 両手光弾用初期化

### StateDef 506100: 表示・巡回・攻撃値の保存

明光弾表示、AfterImage、放出粒子、三次元巡回移動、A/B/C分岐および攻撃判定に必要な値をHelper自身へ保存する。生成元の発出管理Helperから生成時の共通経過tick、現在の分岐選択および選択時刻をコピーし、60度の位相間隔へ生成時刻分の回転角を加えて初期角度を求める。生成後は明光弾表示Controllerが発出管理Helperの分岐と選択時刻を毎tick同期してから表示補間を実行し、同じ値を後続の巡回移動Controllerも使用する。

設定保存後はStateDef `506990`へ遷移する。変数割当は[明光弾Helper変数](var-list-helper-506000.md)、[三次元巡回移動Helper変数](var-list-helper-507000.md)および[明光弾攻撃判定Helper変数](var-list-helper-508000.md)を参照する。

## 共通基盤接続

### StateDef 506990: 複合責務の開始

責務bitmapを`448`として、明光弾マスク`64`、三次元巡回移動マスク`128`、攻撃判定マスク`256`を同時に設定する。共通経過tickを`0`、最終実行tickを`599`、初期化完了bitを有効にし、StateDef `599000`へ接続する。

## 明光弾表示

### StateDef 506900: 加算表示・残像・放出粒子

Action `506000`を`addalpha`のAlpha `192,256`で表示し、色反転は行わない。発出時のX・Y倍率は`0.80`とする。Aはこの表示scaleを維持して発出開始から`120tick`で終了する。B/Cは分岐開始時のscaleから`4tick`でX・Yとも基準倍率の`1.5`倍（実倍率`1.20`）へ補間する。B/Cは寿命末尾20tickで縮小する。

生成から11tick後に、長さ`8`、`timegap=2`、`framegap=2`の薄い加算AfterImageを開始する。残像も色反転を行わない。同じtickにフィボナッチ・ライトHelper `502020`を一体生成し、親光弾へ追従する少数の外向き粒子光を継続表示する。

PlayerPush、被弾および影を無効化し、同じtickの三次元巡回移動ルーターStateDef `599080`へ進む。座標と描画優先順位は本StateDefで変更しない。

## Action 506000

Sprite Group `16000`の要素`0`〜`33`を1tickずつ反復する。合成はStateDef `506900`の`Trans`で行う。中心から上下左右12pxのClsn1を全要素へ適用する。

# stcommon共有ステート

`cns/common1.cns`にあるWinMUGEN 2002.04.14系共有ステートの要約。StateDef `100`、`105`、`106`、`191`は固有実装を優先して削除しているため、[デフォルトステート](default.md)を参照する。

## 基本動作と安全処理

| StateDef | 機能 |
| --- | --- |
| `0` | 操作可能な浮遊待機。Action `0`、Y速度0、X速度停止。死亡時は`5050`へ移る |
| `10`、`11`、`12` | しゃがみ入口を拒否し、直ちに操作可能な`0`へ戻す |
| `20` | 定数の前後歩行速度とAction `20`・`21`を適用する |
| `40` | ジャンプ入口を拒否し、直ちに操作可能な`0`へ戻す |
| `52` | 空中着地時にY位置・速度を0へ補正し、操作可能な`0`へ戻す |

## ガード

| StateDef | 機能 |
| --- | --- |
| `120` | 姿勢別の開始Action `120`〜`122`を選び、`130`〜`132`または終了`140`へ移る |
| `130` | 立ちガード。しゃがみで`131`、終了条件で`140`へ移る |
| `131` | しゃがみガード。入力解除で`130`、終了条件で`140`へ移る |
| `132` | 空中ガード。重力と接地を処理し、`130`、`52`、`140`へ分岐する |
| `140` | 姿勢別の終了Action `140`〜`142`を再生し、開始時から操作を返す |
| `150`→`151` | 立ちガードの揺れと後退。硬直終了後に`130`へ戻る |
| `152`→`153` | しゃがみガードの揺れと後退。硬直終了後に`131`へ戻る |
| `154`→`155` | 空中ガードの揺れと吹き飛び。接地時に`130`または`52`へ移る |

## ラウンド状態

| StateDef | 機能 |
| --- | --- |
| `170` | 時間切れ敗北Action、位置固定、常時無敵を維持する |
| `175` | 引き分けAction。未定義なら`170`を使用する |
| `190` | 登場前Actionから固有StateDef `191`へ移る |
| `5500` | コンティニューAction、位置・速度固定を維持する |
| `5900` | ラウンド1で全`var`・`fvar`を0にし、`190`へ移る |

## 被弾

| StateDef | 機能 |
| --- | --- |
| `5000`→`5001` | 立ち被弾の揺れと後退。打ち上げ・転倒時は`5030`へ分岐し、通常は`0`へ戻る |
| `5010`→`5011` | しゃがみ被弾の揺れと後退。打ち上げ・転倒時は`5030`、通常は`11`へ戻る |
| `5020` | 空中被弾Actionを選び、`5030`へ移る |
| `5030` | 空中吹き飛び。非転倒は`5040`、転倒は`5050`、Action終了時は`5035`へ移る |
| `5035` | 空中被弾の移行Action。条件により`5040`または`5050`へ移る |
| `5040` | 非転倒回復。死亡時は`5050`、接地時は`52`へ移る |
| `5050` | 落下Actionと受け身判定。受け身は`5200`・`5210`、接地は`5100`へ移る |
| `5070`→`5071` | 足払い被弾の揺れと吹き飛び。地面から15px以内で`5110`へ移る |
| `5080` | ダウン追撃の揺れ。Y速度0なら`5081`、それ以外は`5030`へ移る |
| `5081` | ダウン追撃の後退。接地済みフラグを立てて`5110`へ移る |

## 接地・ダウン・受け身

| StateDef | 機能 |
| --- | --- |
| `5100` | 落下接地、速度減衰、落下ダメージ、効果音・土煙を処理し、`5101`または`5110`へ移る |
| `5101` | 地面バウンド。Y加速度`0.4`を加え、再接地で`5110`へ移る |
| `5110` | ダウンAction、追加落下ダメージ、速度減衰を処理する。死亡時は`5150`へ移る |
| `5120` | 無敵付き起き上がりAction。終了時に操作可能な`0`へ戻る |
| `5150` | KOダウン表示と常時無敵を維持し、自動復帰しない |
| `5200` | 地上受け身準備。接地で`5201`へ移る |
| `5201` | 地上受け身。速度`(-0.15,-3.5)`、短時間無敵、発光、土煙を適用する |
| `5210` | 空中受け身。開始4tick固定、15tick無敵、20tick目に操作を返し、接地で`52`へ移る |

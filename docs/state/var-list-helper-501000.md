# 重力球Helper変数

StateDef `501000`が全設定値を保存し、StateDef `501900`が同じ変数契約で共通実行する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 総経過tick・浮遊位相 |
| `var(1)` | 出現時間 |
| `var(2)` | 全寿命 |
| `var(3)` | 拡縮・回転周期 |
| `var(4)` | Helper本体の現在拡縮率 |
| `var(5)`〜`var(10)` | 拡縮・回転の区間境界tick |
| `var(11)`〜`var(14)` | Helper本体、前面層、内部層、背面層の描画優先順位 |
| `var(15)`、`var(16)` | 内部層の加算α値 |
| `var(17)`、`var(18)` | Helper本体Action、三層Explod Action |
| `var(19)`〜`var(21)` | Helper本体のPalFX乗算RGB |
| `var(22)`〜`var(26)` | 拡縮率の初期値と区間別増減値 |
| `var(27)` | 前面層脈動周期 |
| `var(28)` | 初期回転角の乱数範囲 |
| `var(29)` | 間欠処理の除数 |
| `var(30)` | 消滅時間 |
| `var(31)` | 中心収縮層Action |
| `var(32)` | 中心収縮層Explod ID |
| `var(33)` | 中心収縮層の描画優先順位 |
| `var(34)` | 中心収縮層の収縮周期 |
| `var(35)`、`var(36)` | 中心収縮層のX・Y位置補正 |
| `var(37)` | 惑星リング生成周期 |
| `var(38)`、`var(39)` | 惑星リングの左・右Helper IDおよび初動StateDef |
| `var(40)` | 重力球内部フィボナッチ・ライト生成周期 |
| `var(41)` | 重力球内部フィボナッチ・ライトHelper IDおよび初動StateDef |
| `var(42)`、`var(43)` | StateDef `1100`中に使用する`BindToRoot`のX・Y相対位置 |
| `var(44)` | 生成時のRoot追従ラッチ。StateDef `1100`終了時に`0`へ戻し、再有効化しない |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(2)` | 前面層の生成時倍率 |
| `fvar(3)`、`fvar(4)` | 前面層の基準倍率と脈動幅 |
| `fvar(5)` | 内部層倍率 |
| `fvar(6)` | 背面層倍率 |
| `fvar(7)` | Helper本体の拡縮率係数 |
| `fvar(8)`、`fvar(9)` | 浮遊振幅と周期 |
| `fvar(10)`〜`fvar(13)` | 区間別の回転加算角度 |
| `fvar(14)` | 出現・消滅倍率の現在進行率 |
| `fvar(15)`〜`fvar(17)` | 本体準拠浮遊波形の係数 |
| `fvar(18)`、`fvar(19)` | 現在tick・次tickの浮遊位相 |
| `fvar(20)`、`fvar(21)` | 現在tick・次tickの浮遊波形値 |
| `fvar(22)`、`fvar(23)` | 中心収縮層の開始・終了倍率 |
| `fvar(24)` | 中心収縮層の現在進行率 |

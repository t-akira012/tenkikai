# 中心衝撃波Helper変数

StateDef `503000`が全設定値を保存し、StateDef `503990`から共通基盤へ接続してStateDef `503900`が同じ変数契約で実行する。責務bitmap、終了状態およびアニメーション終了型の指定は[非常駐Helper共通変数](var-list-helper-transient-common.md)を使用する。

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | 表示Action |
| `var(1)` | 描画優先順位 |

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | X・Y表示倍率 |

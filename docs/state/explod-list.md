# Explod一覧

この文書は、TENKIKAIの定義ファイルにある `Explod` コントローラーを列挙する。IDを明示したExplodは存在しない。

## StateDef 191: 登場時の飛翔演出

| 項目 | 定義 |
| --- | --- |
| 定義ファイル | `cns/state.cns` |
| 生成条件 | `RoundState!=0` を初めて満たしたとき |
| Action | `191` |
| 基準座標 | `p1` |
| 初期位置 | `(260,-90)` |
| 初速度 | `(-4.2,-7)` |
| 加速度 | `(0,0.32)` |
| 寿命 | `48` tick |

Stateコントローラーの `persistent=0` により、このステート滞在中に1回だけ生成される。

## StateDef 191: 登場時の付随演出

| 項目 | 定義 |
| --- | --- |
| 定義ファイル | `cns/state.cns` |
| 生成条件 | Action要素7の開始から1tick後 |
| Action | `192` |
| 基準座標 | `p1` |
| 初期位置 | `(60,-70)` |
| 初速度 | `(2,-4)` |
| 加速度 | `(0,0.32)` |
| 寿命 | `35` tick |

登場Actionの進行に合わせて本体付近から生成される。

## 集計

`Explod` コントローラーは2個である。いずれも `id` を指定していない。

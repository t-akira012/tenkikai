# ヘルパーステート

この文書は、`cns/helper.cns` にあるヘルパー用StateDefを説明する。

## 頭部ヘルパー

### StateDef 99000: ヘルパー振り分け

ヘルパーID `99001` であればStateDef `99001` へ移る。それ以外のヘルパーには、このStateDef内で追加動作を行わない。

### StateDef 99001: 頭部待機

Action `99001` を表示し続ける。向きが本体と異なる場合は反転し、本体の位置、浮遊オフセット、透明度、不可視化、残像を個別StateDefで更新する。末尾の `null` コントローラーにより、このステートから自動では退出しない。

## オーラヘルパー

### StateDef 99002: オーラ常駐

本体の位置・向き・アニメーション・描画オフセットへ毎フレーム追従する。描画倍率を周期的に変化させ、透過表示と専用AfterImageを適用する。

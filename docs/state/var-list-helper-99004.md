# the_controller Helper変数一覧

## 通常変数

| 変数 | 用途 |
| --- | --- |
| `var(0)` | オーラバウンド状態ビットフィールド |
| `var(1)` | オーラバウンドの拡大残りtick。即時拡大する用途では`0` |
| `var(2)` | AngleDraw演出要求bitフィールド |
| `var(3)`、`var(4)` | 異形回避Head回転の残り時間、全体時間 |
| `var(5)`、`var(6)` | 異形回避Body縮小の残り時間、全体時間 |
| `var(7)` | 本体自由傾斜の残存時間・角速度コードビットフィールド |
| `var(8)` | Root画面外移動許可boolean。`0`は通常の画面内拘束、`1`は画面外移動許可 |
| `var(9)` | 本体アニメーション変更・時間付き処理予約ビットフィールド |
| `var(10)` | 前方短距離ワープBody変形の残り時間 |
| `var(11)` | Helper Armor状態ビットフィールド |
| `var(12)` | Helper Armor configビットフィールド |
| `var(15)` | 保存済みRootアニメーション番号 |
| `var(16)` | Rootアニメーション変更時の`abs(root,animtime)` |
| `var(22)` | Body・Head系表示変換制御ビットフィールド |
| `var(23)` | 前方短距離ワープBody変形の全体時間 |
| `var(24)` | Head眼球表示制御ビットフィールド |

### `var(0)` bit割当

| bit | 用途 |
| ---: | --- |
| 0 | オーラバウンド有効フラグ |
| 1〜15 | 消費開始までの待機tick、0〜32767tick |
| 16〜31 | 未使用 |

`var(0)`はオーラバウンド開始から終了まで保持する。毎処理周期には初期化せず、待機tickの減算ではbit 0を保持する。オーラバウンド終了時に全体を`0`へ戻す。

### `var(11)` bit割当

| bit | 用途 |
| ---: | --- |
| 0〜15 | Helper Armorが受けた保留ダメージ、0〜65535 |
| 16〜23 | 次のダメージ受付までの無敵期間。configにより0〜127tickを登録 |
| 24 | PlayerPush無効化フラグ |
| 25 | Helper Armor無敵フラグ |
| 26〜31 | 未使用 |

保留ダメージと無敵期間は処理周期をまたいで保持し、それぞれの領域だけを消費・減算する。解決済みダメージが65535を超える場合は保留ダメージを65535とする。無敵期間は`var(12)`のconfigから登録する。bit 24とbit 25は毎処理周期の先頭で両方を解除し、Rootの状態に該当するbitだけを再設定する。フラグ初期化ではbit 0〜23を保持する。

### `var(12)` bit割当

| bit | 用途 |
| ---: | --- |
| 0〜6 | 自動回復量、0〜127/tick。`0`は自動回復なし |
| 7〜11 | ダメージ減衰率config、0〜25。1段階を元Damageの4%とし、26〜31は25へ制限 |
| 12〜18 | 被弾後無敵時間、0〜127tick |
| 19 | 未使用 |
| 20〜31 | 極大Damage閾値config、0〜32。1段階を100Damageとし、33以上は32へ制限 |

`var(12)`はStateDef `-2`先頭のAI設定欄で毎tick設定する。各Controllerは`IsHelper(99004)`で`the_controller`だけを対象とし、初期化後に項目別の値をビットORする。ダメージ減衰率はconfigを25で除算した倍率とする。極大Damage閾値はconfigへ100を乗算したDamageとし、`0`では極大Damage判定を無効化する。現在値は、自動回復量`0`、ダメージ減衰率config `4`、被弾後無敵時間`30tick`、極大Damage閾値config `30`である。

### `var(2)` bit割当

| bit | マスク | 用途 |
| ---: | ---: | --- |
| 0 | `1` | 異形回避中のHead回転・縮小 |
| 1 | `2` | 異形回避中のBody縮小 |
| 2 | `4` | 本体自由傾斜 |
| 3 | `8` | 未使用 |
| 4 | `16` | 本体アニメーション変更・時間付き処理 |
| 5 | `32` | 前方短距離ワープのBody変形 |
| 6〜31 | — | 未使用 |

### `var(9)` bit割当

| bit | 用途 |
| ---: | --- |
| 0〜8 | 経過tick、0〜511 |
| 9〜17 | 予約全体tick、0〜511 |
| 18〜22 | 処理type、0〜31 |
| 23〜31 | 未使用 |

処理type `0`は予約なし、`1`は異形回避または本モーションの地上再出現後の16tick復帰、`2`は画面横断突進再出現後の5tick復帰、`3`はラウンド終了時接地後の4tick復帰、`4`は本モーション初期出現後の16tick上下反転復元、`5`は落下・跳ね返り中の1tick上下反転維持とする。共通時間処理は経過tickだけを更新し、type別の完成値計算は独立したControllerで行う。本予約は最大約5秒とするRoot本体アニメーション変更に伴う処理だけに使用し、長時間化し得るHelperや背景などへ使用しない。詳細は[ADR 031](../ADR/031-root-animation-timed-processing-request.md)に従う。

### `var(7)` bit割当

| bit | 用途 |
| ---: | --- |
| 0〜8 | 本体自由傾斜の残存有効tick、0〜511tick |
| 9〜15 | 角速度コード、0〜127。`0.5`度/tick単位 |
| 16〜31 | 未使用 |

残存時間の減算ではbit 9〜31を保持する。要求登録ではbit 16〜31を保持し、下位16bitへ残存時間と角速度コードを設定する。Rootが対象StateDefにいる間は1tickリースを再設定し、離れた後は保持した角速度で現在角度を0へ戻す。

### `var(22)` bit割当

| bit | マスク | 用途 |
| ---: | ---: | --- |
| 0 | `1` | Headだけの部分非表示 |
| 4 | `16` | Head Aura Offset非同期 |
| 5 | `32` | Head Aura AngleDraw非同期 |
| 6 | `64` | Body AngleDraw適用 |
| 7 | `128` | Body Aura AngleDraw適用 |
| 8 | `256` | Root、Head、Head Aura、Body Auraの全体非表示とAfterImage消去・再生成抑止 |
| 1〜3、9〜31 | — | 未使用 |

`var(22)`は毎処理周期の先頭で`0`へ初期化し、その周期内の表示・変換処理が各完成bitをORで追加する。bit 8が有効な間、Rootと各常駐表示Helperは非表示とAfterImage停止・消去を同期する。周期途中で全体を再初期化しない。

### `var(24)` bit割当

| bit | マスク | 用途 |
| ---: | ---: | --- |
| 0 | `1` | 相手との距離による眼球位置同期 |
| 1 | `2` | Sprite `1,1`の完成表示 |
| 2 | `4` | Sprite `1,2`の完成表示 |
| 3 | `8` | Sprite `1,3`の完成表示 |
| 4〜31 | — | 未使用 |

`var(24)`は毎処理周期の先頭で距離同期bitだけを有効にした`1`へ初期化する。眼球表示ルーターが同じ周期内に完成表示bitを一つ追加する。

## 浮動小数点変数

| 変数 | 用途 |
| --- | --- |
| `fvar(0)` | オーラバウンド残量 |
| `fvar(1)` | オーラバウンドの毎tick消費量 |
| `fvar(2)`〜`fvar(4)` | Head完成AngleDrawの角度、X倍率、Y倍率 |
| `fvar(5)`、`fvar(6)` | Body系完成AngleDrawのX倍率、Y倍率 |
| `fvar(7)` | 本体自由傾斜の現在角度・Body系完成角度 |
| `fvar(8)` | Body系完成Y Offset |
| `fvar(9)`〜`fvar(11)` | Head Aura完成AngleDrawの角度、X倍率、Y倍率 |
| `fvar(12)`、`fvar(13)` | Head完成X・Y Offset |
| `fvar(14)`、`fvar(15)` | Head Aura完成X・Y Offset |
| `fvar(16)`、`fvar(17)` | Head系の完成X・Y Pos補正 |
| `fvar(18)` | オーラバウンドの毎tick拡大量。即時拡大する用途では`0` |
| `fvar(19)` | 本体自由傾斜の目標角度 |
| `fvar(20)` | Helper Armor通常Damage計算時のRoot Life比率 |
| `fvar(21)` | Helper Armor通常Damage計算時の減衰後Damage |

`var(15)`と`var(16)`の更新順序は[Rootアニメーション時間保持規約](../AGENTS.root-animtime.md)に従う。

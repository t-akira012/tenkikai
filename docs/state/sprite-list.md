# Sprite一覧

`binary/sprite.sff`へ登録されているSpriteをgroup単位で記録する。機械可読な番号、軸、素材パスおよびパレット指定の正本は`assets/sprite.json`とし、この文書は画像内容と用途を把握するための一覧とする。

画像の意味は、Sprite画像全体と連番変化を目視した結果である。AIRまたはCNSから参照されていない素材については、将来の具体的な用途を確定せず、画像から読み取れる表現だけを記載する。

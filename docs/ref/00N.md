# 00N構造分析

## 調査対象

00Nは、Rootと複数の常駐Helperが表示、入力、移動および攻撃を分担するWinMUGENキャラクターである。本稿では、球状の本体表示と、その周囲に形成されるエネルギー表現を扱う。

調査対象はTENKIKAIディレクトリから相対パスで次のディレクトリである。

```text
../00n
```

## Rootと常駐Helper

`st2.cns`はPlayer型のHelper ID `2`、`3`、`4`、`5`、`9`を生成する。`st.cns`のStateDef `-2`は各Helperを専用の管理Stateへ送る。

| Helper ID | 主な管理State | 読み取れる役割 |
| --- | --- | --- |
| `2` | 入力・状態管理系 | 入力、状態遷移および防御処理 |
| `3` | `300000`番台 | 付随表示および攻撃演出 |
| `4` | `400000`番台 | Helper 3と別系統の付随表示および攻撃演出 |
| `5` | `500000`番台 | フラクタル変形、技別エネルギー表示、黄金角粒子 |
| `9` | `900000`番台 | 移動、浮遊、本体表示および攻撃時の運動 |

球状の本体はHelper 9が管理するAction `6000`の三層Explodによって形成される。Helper 5は技に応じて、その上へフラクタル、エネルギー球、粒子などを重ねる。

## Action 6000による球状本体

Action `6000`はSprite Group `6000`の0〜33を1tickずつ再生する。全要素に加算透過指定`A`があり、34フレームの内部流動を連続表示する。

Helper 9は同じAction `6000`を三つのExplodとして生成する。三層は同一位置へBindされ、それぞれ異なる合成、倍率、描画優先順位を持つ。

| Explod ID | 合成 | 基準倍率 | 描画優先順位 | 役割 |
| --- | --- | --- | --- | --- |
| `6000` | 減算 | `0.65`を中心に微小脈動 | `13` | 外側の暗い輪郭と脈動 |
| `6001` | 加算α `128,256` | `0.65` | `10` | 内部の発光と流動 |
| `6002` | 減算 | `0.89` | `6` | 奥側の暗い球殻 |

Explod `6000`と`6001`は、`ModifyExplod`で水平・垂直反転を不規則に切り替える。連続する34フレームへ反転差を加えることで、内部模様が一定方向へ流れるだけでなく、球面内部で攪拌されるように見える。

三層の描画順は、手前の減算層、中央の加算層、奥の減算層となる。同じアニメーションを異なる合成と倍率で重ねるため、外周の黒さを保ちながら内部光の運動が残る。

## Helper 5の補助エネルギー表示

### Action 500020・500021

Action `500020`と`500021`はSprite Group `7321`を使用する。フレーム0から6へ進んだ後に0へ戻る往復系列で、全要素に加算透過指定`A`がある。

StateDef `500020`と`500021`は、このアニメーションへ次の処理を重ねる。

- `AngleDraw`による回転と倍率変化
- `PalFX`による色調強調
- Action `7311`の補助Explod
- Action `7300`の粒子Explod
- 技の進行に応じた拡大、収縮および消去

TENKIKAIでは、Sprite Group `7320`と`7321`がそれぞれ`18551`と`18552`に対応する。

### Action 7311

Action `7311`はSprite Group `7310`の13から0を逆順再生する加算透過アニメーションである。球体へBindされる補助Explodとして使用され、中心付近のエネルギー変化を球体本体と同期させる。

TENKIKAIでは、この役割にAction `16998`が対応する。

## 黄金角粒子

StateDef `500020`と`500021`はAction `7300`の粒子を黄金角で分散させる。

```text
angle = index * 137.509549 degree
x = angle * cos(angle)
y = angle * sin(angle)
```

生成位置と反対向きの速度および加速度を与えることで、粒子は球体周囲から中心方向へ収束する。黄金角によって十字状や等間隔の配置を避け、少数の粒子でも連続した場を形成する。

## フラクタル変形

Helper 5のStateDef `501000`は、Sprite Group `21000`〜`21500`を使用する複数のAction系列から表示を選択する。StateDef `501099`と`501100`は収縮と膨張を対で管理し、回転方向、再生方向、色調、AfterImageおよび背景色を組み合わせる。

この系列は球状本体のAction `6000`三層へ重ねる変形表現であり、球体の内部模様、径、回転および周囲の光量を大きく変化させる。

## 浮遊

Helper 9は上下方向の補正値を区間ごとに増減させる。上昇と下降を継続的に繰り返し、静止中にも表示位置を完全停止させない。

球状本体の内部流動、三層の倍率差、微小脈動、反転差および上下浮遊が同時に動くことで、空間に浮かぶエネルギー体として見える。

## TENKIKAIとの素材対応

| 00N | TENKIKAI | 用途 |
| --- | --- | --- |
| Action・Sprite Group `6000` | Action・Sprite Group `16000` | 球状本体の三層描画 |
| Sprite Group `7320` | Sprite Group `18551` | 補助エネルギー表示 |
| Sprite Group `7321` | Sprite Group `18552` | 補助エネルギー表示 |
| Action `7311` | Action `16998` | 球体へ同期する補助光 |

TENKIKAIでAction `16000`を使用する場合は、00NのAction `6000`と同じく各要素へ加算透過指定`A`を設定する。球体は`16000`の三層描画を基礎とし、`18552`と`16998`を用途に応じて重ねる。

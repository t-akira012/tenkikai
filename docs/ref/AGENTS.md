# 別キャラクターの構造分析リファレンス

`docs/ref/`は、TENKIKAIの設計および実装を検討するために調査した、別キャラクターの構造分析を記録する。

## 文書の責務

- 調査対象のパスおよび参照したファイルを明記する。
- CNS、CMD、AIR、SFFなどから確認できる実装事実と、挙動から導いた推論を区別する。
- TENKIKAIへ応用できる構造、表現手法、数学的処理と、応用時の注意点を記録する。
- 調査対象のState番号、変数番号、素材、実装上の制約を、TENKIKAIの規約として扱わない。

## 他文書との関係

- `docs/ref/`は参考資料であり、TENKIKAIの設計要求を定めない。
- 採用する表現と仕様は`docs/design/`へ、設計判断と理由は`docs/ADR/`へ記録する。
- 現在のCNSおよびCMD実装から読み取ったTENKIKAIの動作は`docs/state/`へ記録する。
- 別キャラクターの実装をTENKIKAIへ移植する場合は、TENKIKAIの各規約と確定済み設計を優先する。

## 調査時の制約

- 明示的な許可がない限り、調査対象の別キャラクターを変更しない。
- 文字化けしたコメントや用途が不明確な処理は、断定せず推論として記載する。
- 不具合対策、環境依存処理、キャラクター固有の防御処理を、演出構造と混同しない。

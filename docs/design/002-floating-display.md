# 002: Floating Display

## 目的

本体の上下浮遊感を表示上再現する。移動処理とは分離し、立ち状態と歩行状態に限定して本体の位置を周期的に上下させる。

## 対象状態

次の状態で本体のrootスプライトを上下移動させる。

- `stand`
- 前歩き
- 後ろ歩き
- `air`（浮遊移動中を含む）

`crunch`、被弾、ダウン、登場、勝利、その他の状態では、この表示用上下移動を適用しない。

## 表示方法

- 本体のrootスプライトに対して、`Pos Y` を一定周期で変化させる。
- 上下幅と周期は、浮遊して見える範囲で調整する。
- 本体の頭部ヘルパーは、本体の表示位置に追従する既存処理を利用する。
- これは表示上の位置移動であり、攻撃判定やStateTypeの判定に使用する浮遊移動とは区別する。

## 実装方針

StateDef `-3` の常時監視から、現在のStateDefと状態種別を確認して対象状態だけへ `PosAdd` または同等の位置移動を適用する。既存の浮遊移動によるY速度・着地処理と競合しないようにする。

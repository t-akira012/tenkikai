# 001: Floating Movement and Display

## 目的

ジャンプを使わず、TENKIKAIが常に空中を遊泳しているように見える移動と浮遊感を作る。

移動行動の予備動作、移行、終了を含む静止回避の共通原則は、[動きの連続性](010-continuous-floating-motion.md)に従う。

## 動作モデル

基準位置は地面とする。↑入力中は上方向へ移動し、入力を解除すると現在の高度からゆっくり下降する。空中で↓を入力した場合は、下降を能動的に行う。地面まで落下させず、設定した浮遊下限付近で滞空する。

画面上部へ近づくと、上昇を急に止めず、上部の余白に応じて下向きの制動を強める。高度が上部制動帯から戻ると、追加した制動と重力も徐々に弱まり、通常の浮遊へ戻る。

空中で←→を入力すると、空中歩行へ移行して前後へ遊泳する。前後・上下の入力開始時は目標速度へ徐々に加速し、入力を解除した後も直ちに静止せず、残った速度を減速させながら浮遊の余韻を保つ。方向反転時は現在の運動を減速してから反対方向へ加速する。

上下移動と浮遊感表示は別の動きとして扱う。上下移動は高度を変え、浮遊感表示は身体の位置を中心に小さく揺らす。揺れは中央で立ち止まらず、上下の反転まで連続した空中遊泳のリズムを保つ。本体と頭部は同じ流れを共有しつつ、頭部の揺れ幅を変えて身体の一体感を保つ。

Y座標が0では `stand`、地上で↓入力中は `crunch`、0より上に浮いている間は `air` とする。

## 実装手段

浮遊移動はStateDef `-3`、入力による移動状態の切り替えはStateDef `-1`、空中歩行はStateDef `60`・`61`で管理する。継続移動は期限付きRoot移動要求からX・Y速度へ反映し、接地など瞬時の位置確定だけを位置操作で扱う。浮遊感表示は描画オフセットで扱う。

## 現在の設定値

### 上下移動

- 上昇・下降：期限付き垂直移動要求
- 上入力：目標Y速度`-6`、加減速度`1/tick`。上部制動帯では目標速度を0へ近づける
- 空中の下入力：目標Y速度`6`、加減速度`1/tick`
- 無入力かつ`Pos Y < -40`：目標Y速度`1`
- 無入力かつ`-40 <= Pos Y < 0`：目標Y速度`0`、加減速度`0.166667/tick`
- 無入力時：高度に応じて下降または停止する目標Y速度へ移行
- 上部制動帯：画面上端 `Pos Y=-180` に対し、`Pos Y=-90` から制動を開始
- 上部制動：画面上端へ近づくほど上昇時の目標速度を0へ近づける
- 下降時の上部加速：上部制動帯の深さに比例して増加
- 上部制動解除：`Pos Y >= -90` で追加補正を0へ戻す
- 浮遊下限到達時：Y速度を0にし、その時点の位置を維持

### 前後移動

- 地上前後移動：期限付き水平移動要求
- 空中前歩き：StateDef `60`
- 空中後ろ歩き：StateDef `61`
- 前方：目標X速度`3`、加減速度`0.5/tick`
- 後方：目標X速度`-2`、加減速度`1/3tick`
- 入力解除後：開始時の`abs(Vel X)`が`3`以下なら32tick、`3`を超える場合は16tickの半コサイン曲線で停止

### 浮遊感表示

- 表示方法：`Offset Y`
- 対象：立ち、前歩き、後ろ歩き、空中前歩き、空中後ろ歩き、通常浮遊
- 対象外：しゃがみ、被弾、ダウン、登場、勝利
- 位相：本体と頭部Helperで同期
- 本体の表示範囲：`Offset Y=-6`～`+10`
- 頭部Helperの表示範囲：`Offset Y=-4`～`+8`

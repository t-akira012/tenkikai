# 001: Floating Movement

## 目的

ジャンプを使用せず、TENKIKAI固有の浮遊移動として上下移動を実装する。これは設計定義であり、実装は別途行う。

## 状態

キャラクターのY座標に応じて、StateTypeを次のように扱う。

| 条件 | 状態 |
| --- | --- |
| Y座標が `0` | `stand` |
| Y座標が `0` より上 | `air` |
| `stand` 中に下方向入力 | `crunch`（しゃがみ） |

浮遊中は常に `air` とし、地上へ戻ってY座標が `0` になった時点で `stand` へ戻す。`stand` 中の下方向入力による `crunch` は、地上にいる場合だけ有効とする。

## 移動

- ジャンプの代わりに上方向へ移動する。
- 上方向の移動速度は歩行程度を基準にする。
- 上方向入力がない場合は、自然に下方向へ移動する。
- 画面上部の一定位置を上限の目安とし、仮の基準値を400pxとする。
- 上限を超えたあたりから、Y軸下方向への重力加算をエミュレートして上昇を減速する。
- 下降してY座標が `0` に到達した場合は、地上状態へ戻す。

## 管理

浮遊移動と、Y座標に基づく `stand`・`crunch`・`air` の状態変更はStateDef `-3` で管理する。

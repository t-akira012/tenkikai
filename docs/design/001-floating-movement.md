# 001: Floating Movement and Display

## 目的

ジャンプを使用せず、TENKIKAI固有の浮遊移動として上下移動を実装する。待機・歩行中も本体を周期的に上下させ、浮遊感を表示する。

## 状態

キャラクターのY座標に応じて、StateTypeを次のように扱う。

| 条件 | 状態 |
| --- | --- |
| Y座標が `0` | `stand` |
| Y座標が `0` より上 | `air` |
| `stand` 中に下方向入力 | `crunch`（しゃがみ） |

浮遊中は常に `air` とし、地上へ戻ってY座標が `0` になった時点で `stand` へ戻す。`stand` 中の下方向入力による `crunch` は、地上にいる場合だけ有効とする。

## 移動

ジャンプの代わりに上方向へ移動する。↑入力中は位置加算で上昇し、入力を解除すると上方向の位置加算を停止する。上昇中のY速度はリセットし、入力解除後は重力をY速度として適用する。上方へ移動した後は重力で下降し、接地時に位置とY速度を初期化する。

## 前後移動

地上・空中とも、前後移動は位置加算で行う。空中前歩きと空中後ろ歩きは、入力をStateDef `-1` で検出して専用ステートへ遷移する。水平速度は使用せず、向きの計算に `facing` を参照しない。

## 浮遊感表示

立ち状態、前歩き、後ろ歩き、空中前歩き、空中後ろ歩き、通常浮遊に対して、本体の描画位置を周期的に上下させる。浮遊感表示は `Offset Y` で行い、実際のRoot `Pos Y`、重力、接地、StateType、当たり判定には影響させない。しゃがみ、被弾、ダウン、登場、勝利などには適用せず、対象外の状態ではオフセットを初期位置へ戻す。

頭部Helperにも浮遊オフセットを適用し、本体と周期・位相を同期させる。ただし上下の移動範囲は本体と変えることで、頭部と胴体の相対位置に自然な差を残す。

浮遊感表示では絶対的なオフセット値を指定する。前フレームとの差分計算と、差分計算用の変数は使用しない。軌道には三角波、弱い非線形速度補正、中央加速項を組み合わせ、中央で停止せず、上下の頂点側でも速度を維持しながら反転させる。

### 速度変化

三角波によって往復中の基礎速度を維持する。弱い非線形速度補正によって頂点側の速度を調整し、中央加速項によって中央付近の減速や一時停止を防ぐ。

## 管理

浮遊移動、浮遊感表示、Y座標に基づく `stand`・`crunch`・`air` の状態変更はStateDef `-3` で管理する。入力はStateDef `-1` で専用変数へ反映し、`-3` の物理処理は入力情報へ直接依存しない。実際の浮遊移動には `Pos Y`、浮遊感表示には `Offset Y` を使用して責務を分離する。

## 現在の設定値

### 上下浮遊移動

- 上昇移動：`PosAdd Y = -6 / frame`
- 上昇中のY速度：`Vel Y = 0`
- 上昇入力状態：`var(3)=1`
- 通常浮遊・下降状態：`var(3)=0`
- 重力開始条件：`Pos Y <= -40`
- 重力加算：`const(movement.yaccel) * 0.1 = 0.044 / frame`
- 接地時の位置：浮遊移動の接地処理では `Pos Y = 0`。浮遊感表示の振動中は表示処理による上下移動を許可する。
- 接地時のY速度：`Vel Y = 0`

### 前後移動

- 地上前進：`PosAdd X = 6 / frame`
- 地上後退：`PosAdd X = -4 / frame`
- 空中前歩き：`StateDef 60`
- 空中後ろ歩き：`StateDef 61`
- 空中歩行の水平速度：`Vel X = 0`
- しゃがみ入力状態：`var(4)=1`

### 浮遊感表示

- 表示方法：`Offset Y`
- 対象：立ち、前歩き、後ろ歩き、空中前歩き、空中後ろ歩き、通常浮遊
- 対象外：しゃがみ、被弾、ダウン、登場、勝利
- 基準：初期表示位置を中心とした周期運動
- 位相：本体と頭部Helperで同期
- 本体の表示範囲：`Offset Y=-6`～`+10`
- 頭部Helperの表示範囲：`Offset Y=-4`～`+8`

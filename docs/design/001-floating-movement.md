# 001: Floating Movement and Display

## 目的

ジャンプを使用せず、TENKIKAI固有の浮遊移動として上下移動を実装する。待機・歩行中も本体を周期的に上下させ、浮遊感を表示する。

## 状態

キャラクターのY座標に応じて、StateTypeを次のように扱う。

| 条件 | 状態 |
| --- | --- |
| Y座標が `0` | `stand` |
| Y座標が `0` より上 | `air` |
| `stand` 中に下方向入力 | `crunch`（しゃがみ） |

浮遊中は常に `air` とし、地上へ戻ってY座標が `0` になった時点で `stand` へ戻す。`stand` 中の下方向入力による `crunch` は、地上にいる場合だけ有効とする。

## 移動

ジャンプの代わりに上方向へ移動する。↑入力中は位置加算で上昇し、入力を解除すると上方向の位置加算を停止する。上昇中のY速度はリセットし、入力解除後は重力をY速度として適用する。上方へ移動した後は重力で下降し、接地時に位置とY速度を初期化する。

## 前後移動

地上・空中とも、前後移動は位置加算で行う。空中前歩きと空中後ろ歩きは、入力をStateDef `-1` で検出して専用ステートへ遷移する。水平速度は使用せず、向きの計算に `facing` を参照しない。

## 浮遊感表示

立ち状態、前歩き、後ろ歩き、浮遊中の `air` に対して、本体を周期的に上下させる。しゃがみ、被弾、ダウンなどには適用しない。

StateDef `-3` で、本体の表示位置へ前フレームとの差分を位置加算する。頭部Helperは本体の表示位置へ追従する。

## 管理

浮遊移動、浮遊感表示、Y座標に基づく `stand`・`crunch`・`air` の状態変更はStateDef `-3` で管理する。入力はStateDef `-1` で専用変数へ反映し、`-3` の物理処理は入力情報へ直接依存しない。

## 現在の設定値

### 上下浮遊移動

- 上昇移動：`PosAdd Y = -6 / frame`
- 上昇中のY速度：`Vel Y = 0`
- 上昇入力状態：`var(3)=1`
- 通常浮遊・下降状態：`var(3)=0`
- 重力開始条件：`Pos Y <= -40`
- 重力加算：`const(movement.yaccel) * 0.1 = 0.044 / frame`
- 接地時の位置：`Pos Y = 0`
- 接地時のY速度：`Vel Y = 0`

### 前後移動

- 地上前進：`PosAdd X = 6 / frame`
- 地上後退：`PosAdd X = -4 / frame`
- 空中前歩き：`StateDef 60`
- 空中後ろ歩き：`StateDef 61`
- 空中歩行の水平速度：`Vel X = 0`
- しゃがみ入力状態：`var(4)=1`

### 浮遊感表示

- 対象：`StateNo=0`、`StateNo=20`、`StateNo=21`、`StateType=A`
- 振幅：`100`
- 周期係数：`0.02`
- 1周期：約314 tick
- 60fps換算：約5.2秒
- 最大移動量：約2px/frame

```ini
y = sin(var(0)*0.02)*100-var(2)
var(2) = sin(var(0)*0.02)*100
```

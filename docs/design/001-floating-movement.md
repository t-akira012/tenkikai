# 001: Floating Movement and Display

## 目的

ジャンプを使わず、TENKIKAIが常に空中を遊泳しているように見える移動と浮遊感を作る。

## 動作モデル

基準位置は地面とする。↑入力中は上方向へ移動し、入力を解除すると現在の高度からゆっくり下降する。空中で↓を入力した場合は、下降を能動的に行う。地面まで落下させず、設定した浮遊下限付近で滞空する。

空中で←→を入力すると、空中歩行へ移行して前後へ遊泳する。入力がないときは、上昇・下降の余韻が自然に収まり、空中に留まる。

上下移動と浮遊感表示は別の動きとして扱う。上下移動は高度を変え、浮遊感表示は身体の位置を中心に小さく揺らす。揺れは中央で立ち止まらず、上下の反転まで連続した空中遊泳のリズムを保つ。本体と頭部は同じ流れを共有しつつ、頭部の揺れ幅を変えて身体の一体感を保つ。

Y座標が0では `stand`、地上で↓入力中は `crunch`、0より上に浮いている間は `air` とする。

## 実装手段

浮遊移動はStateDef `-3`、入力による移動状態の切り替えはStateDef `-1`、空中歩行はStateDef `60`・`61`で管理する。実際の高度変更は位置、下降の慣性はY速度、浮遊感表示は描画オフセットで扱う。

## 現在の設定値

### 上下移動

- 上昇：`PosAdd Y = -6 / frame`
- 空中下降：空中↓入力中、`Pos Y < 0` の間 `PosAdd Y = 6 / frame`
- 上昇・能動下降中のY速度：`Vel Y = 0`
- 重力加算条件：`Pos Y < -40` かつ下方向入力なし
- 重力加算：`const(movement.yaccel) * 0.1 = 0.044 / frame`
- 下降速度上限：`Vel Y = 1.0`
- 浮遊下限到達時：Y速度を0にし、その時点の位置を維持

### 前後移動

- 地上前進：`PosAdd X = 6 / frame`
- 地上後退：`PosAdd X = -4 / frame`
- 空中前歩き：StateDef `60`
- 空中後ろ歩き：StateDef `61`
- 水平速度：`Vel X = 0`

### 浮遊感表示

- 表示方法：`Offset Y`
- 対象：立ち、前歩き、後ろ歩き、空中前歩き、空中後ろ歩き、通常浮遊
- 対象外：しゃがみ、被弾、ダウン、登場、勝利
- 位相：本体と頭部Helperで同期
- 本体の表示範囲：`Offset Y=-6`～`+10`
- 頭部Helperの表示範囲：`Offset Y=-4`～`+8`

# 全画面黒

## 概要

画面全体の色を完全な黒へ変化させる画面色エフェクトである。

## 表現

個々の表示要素だけを隠すのではなく、画面全体へ同じ色変化を適用する。発動元の状態が終了した場合も、設定された継続時間が残っている間は暗転を継続する。

## 使用場面

汎用両手光弾発出の予備動作中に開始する。

## 現在の設定値

### エフェクト割り当て

- 分類：画面色エフェクト
- 画面色エフェクト番号：`0`
- 適用対象：画面全体
- 色変化：乗算値`0,0,0`

### 発動

- 発動元：RootのStateDef `1000`
- 発動時刻：`private-time=10`
- 継続時間：60tick

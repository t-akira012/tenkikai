# 004: 背景色変更

## 概要

背景だけへ色変化を適用する共通エフェクトである。現在は基本パターンとして、強大なエネルギーや超必殺技の発動によって周囲の光量が奪われる状態を表現する青暗転を登録している。

## 表現

キャラクター、Helper、ExplodおよびProjectileの色を変えず、背景だけへ`BgPalFX`を適用する。暗い青緑を基調としながら、発動直後に残る明るさを時間経過に従って減少させる。

重力球そのものの描画には含めない。重力球を用いる超必殺技などが、青暗転を必要とする場合に独立して発動する。

## 他エフェクトとの関係

フィボナッチ・ライトおよび中心衝撃波と同時に使用できる。暗転は背景となる光量を抑え、二つの発光エフェクトの輪郭を強調する。

背景色変更Helperを複数同時に生成する場合の優先順位と置換条件は、使用する技の設計で定める。

## 現在の設定値

### エフェクト割り当て

- 分類：背景色変更
- 基本パターン：青暗転
- 適用対象：背景
- 色乗算値：`10,105,135`
- 色加算初期値：`140,190,180`
- 色加算減少量：各成分`8/tick`
- 色変化周期：60tick
- 彩度：`180`
- `BgPalFX`適用時間：2tick
- 基本寿命：600tick

### 実装

- 予約範囲：StateDef `504000`〜`504999`
- 基本パターンHelper ID・出現StateDef：`504000`
- 背景色変更共通実行StateDef：`504900`
- 発動元と発動時刻：使用する技ごとに定める

出現StateDef `504000`が青暗転固有の全設定値をHelper変数へ保存し、同一tickに共通実行StateDef `504900`へ遷移する。

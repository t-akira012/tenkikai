# 007: 横線形衝撃波

## 概要

高速で画面へ侵入する物体の通過線へ、画面を横断する直線状の衝撃波を残す共通エフェクトである。細い線として現れ、中心位置を維持したまま線の法線方向へ対称に厚みを増し、消滅時は徐々に透明になる。

## 動作モデル

単純な長方形を画面幅へ届く横長形状として表示し、発生元の進行角度へ`AngleDraw`で回転する。線方向の長さを保ちながら法線方向だけを拡大し、点や円から広がる衝撃波ではなく、高速通過によって直線状の圧力面が画面へ残る印象を作る。

位置、横倍率、縦の開始倍率と終了倍率、拡大時間、全寿命、フェード開始、フェード時間、透明度、合成方式および描画優先順位は、用途別パターンが個別数値として保存する。すべての用途別パターンは、同じ位置固定、縦拡大、透明度変化および寿命管理の共通モデルを通る。

最初の用途別パターンは画面横断突進の画面侵入時に使用し、突進経路中心から局所法線`-7px`の位置を中心として一組の帯を法線方向へ対称に拡大する。角度`0`度では従来の水平線と画面座標`160,163`を再現する。法線方向へ分離した二組の帯は本パターンへ含めず、必要になった時点で別の用途別パターンとして検討する。

## 他エフェクトとの関係

突進用黒背景暗転および突進用空気波紋と同時に成立する。背景暗転は背景色、空気波紋は移動体周辺の楕円輪郭、横線形衝撃波は画面を横断する直線状の圧力面をそれぞれ担当し、互いを置換しない。

### 画面横断突進パターン

- 基準経路中心：画面座標X `160px`、Y `170px`
- 線中心：基準経路中心から局所法線`-7px`を進行角度で回転した位置
- 表示角度：突進パターン角度。左向きでは鏡映する
- 角度`0`度の線中心：画面座標X `160px`、Y `163px`
- X倍率：`30.0`
- Y倍率：`0.02`から`6.4`
- Y倍率補間：二次イーズアウト
- 拡大時間：`22tick`
- 全寿命：経過tick `0`〜`22`
- フェード開始：`2tick`
- フェード時間：`20tick`
- 加算α：`256,0`から`0,256`
- 合成：`addalpha`
- 描画優先順位：`-5`

# 006: 中心衝撃波

## 概要

エネルギーの発生中心から細い円形輪郭を急速に拡大し、空間へ瞬間的な圧力が放出されたことを表現する共通エフェクトである。

## 動作モデル

小さな円形輪郭を発生中心へ置き、画面規模まで拡大する素材の進行によって一度だけ衝撃波を描く。重力球本体の構成要素には含めず、超必殺技や強いエネルギー発生時に独立して使用する。

## 他エフェクトとの関係

青暗転およびフィボナッチ・ライトと同時に使用できる。中心衝撃波を発動瞬間の輪郭、フィボナッチ・ライトをその後に空間へ残る光として組み合わせられる。

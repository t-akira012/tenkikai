# 009: 三次元巡回移動

## 概要

任意の非常駐HelperをRoot周囲の楕円軌道へ巡回させ、奥行きに応じてRootの前面と背面を通過させる汎用移動エフェクトである。

表示素材、発光、攻撃判定および寿命を所有せず、座標と描画優先順位だけを完成させる。明光弾、三角光弾、重力球など、異なる本体表現へ同じ三次元巡回を合成できる。

## 軌道

Rootへ追従する中心を基準とし、水平半径と垂直半径を持つ楕円上へHelperを配置する。画面上側を奥、画面下側を手前として扱い、奥側ではRootより低い描画優先順位、手前側ではRootより高い描画優先順位へ切り替える。

生成直後は楕円中心から開始し、半コサイン補間によって完成半径まで広がる。角度の進行は拡大中も止めず、複数Helperの位相間隔を維持する。

共通モデルは、一定速の巡回だけでなく、保存された開始時刻、区間時間、目標角速度および目標半径によって角速度と軌道半径を時間変化させる。これにより、同じ巡回責務のまま、加速後の慣性射出と画面規模への軌道拡縮を表現できる。

## 加速後の慣性射出

巡回中の角速度を滑らかに上げ、指定時刻に楕円拘束とRoot追従を解除する。射出速度は、解除直前の巡回座標差から求めた接線速度へ、楕円中心から外向きの放射速度を加えた合成速度とする。

このため、射出時に全光弾を単純な放射方向へ向け直さず、それぞれが持つ位相と直前の回転軌道を慣性として保ったまま散開する。射出後はRootの移動から独立し、完成した合成速度で直進する。

## 画面規模への拡大と収束

巡回中心と位相間隔を保ったまま、水平・垂直半径を画面規模へ滑らかに拡大する。最大半径を一定時間維持した後、同じ補間で本体周囲の半径まで戻す。拡大中は角速度も上昇し、広い軌道でも停止した印象を生じさせない。

## 時間差生成と位相同期

複数のHelperを異なるtickに生成する用途では、生成時刻による回転量を初期位相へ加算する。各Helperが生成後の私有経過tickを使用しても、同じ絶対経過に換算した角度が一致するため、指定した位相間隔を維持できる。

両手光弾では6個を60度間隔とする。180度離れた二個を一組として三回生成し、二個、四個、六個の各段階でも左右の偏りが大きくならない配置とする。

## Rootとの関係

巡回中心は毎tick現在のRoot位置から求める。発出元の親Helperが消滅した後もRootを直接参照するため、Rootが立ち、歩行または別の行動へ移行しても巡回を継続する。

Rootの向きが変化した場合も軌道の位相と回転方向を反転させず、画面座標上で連続した巡回を保つ。

## 他の責務との関係

三次元巡回移動は本体表示責務の後、攻撃判定責務の前に実行する。これにより、攻撃判定は同じtickに完成した光弾位置へ置かれる。

## 現在の設定値

本体周囲の基本巡回はWinMUGEN実機で検収済みである。加速射出と画面規模の拡縮は試験値とし、後日実機確認を行う。

### 予約範囲

- 予約範囲：StateDef `507000`〜`507999`
- 三次元巡回移動共通実行：StateDef `507900`
- 責務bitmap：マスク`128`

### 両手光弾用軌道

- Root基準中心：X `0px`、Y `-55px`
- 水平半径：`60px`
- 垂直半径：`20px`
- 一周時間：`120tick`
- 回転方向：画面座標上で角度を正方向へ増加
- 光弾数：`6`
- 位相間隔：`60`度
- 完成半径までの時間：各光弾の生成から`12tick`
- 奥側描画優先順位：`-1`
- 手前側描画優先順位：`1`
- 奥行きによる表示倍率変更：なし
- Rootの向きによる軌道反転：なし

### 共通分岐時刻

- 分岐開始：選択したA/B/C入力tick。入力なしの場合は発出開始から`180tick`
- 6個の時間基準：発出管理Helperの共通経過tickへ同期

### A：本体周囲回転

- 角速度：`3度/tick`
- 軌道半径：X `60px`、Y `20px`
- 終了：技の発出開始から`180tick`

### B：加速後の慣性射出

- 加速区間：B入力から`0`〜`109tick`
- 加速補間：半コサイン
- 開始角速度：`3度/tick`
- 到達角速度：`30度/tick`
- 射出：B入力から`110tick`
- 放射速度：`12px/tick`
- 射出速度：直前tickの巡回座標差と放射速度の合成
- 射出後：Root追従と楕円拘束を解除
- 画面外終了余白：上下左右`80px`
- 安全上限：B入力から`180tick`

### C：画面規模への拡大と収束

- 拡大：C入力から`0`〜`29tick`の`30tick`
- 最大半径維持：`30`〜`74tick`の`45tick`
- 収縮：`75`〜`89tick`の`15tick`
- 半径補間：半コサイン
- 本体周囲半径：X `60px`、Y `20px`
- 最大半径：X `160px`、Y `100px`
- 開始角速度：`3度/tick`
- 拡大完了時角速度：`6度/tick`
- 最大半径維持および収縮時角速度：`6度/tick`
- 終了：C入力から`90tick`

### 座標式

```text
角度 = 前tick角度 + 現在角速度
展開率 = (1 - cos(pi * Helper私有経過tick / (展開時間 - 1))) / 2
X = Root X + 中心X + 水平半径 * 展開率 * cos(角度)
Y = Root Y + 中心Y + 垂直半径 * 展開率 * sin(角度)
```

Bの射出時は次の速度へ切り替える。

```text
接線速度 = 現在の巡回相対座標 - 前tickの巡回相対座標
射出速度X = 接線速度X + 放射速度 * cos(角度)
射出速度Y = 接線速度Y + 放射速度 * sin(角度)
```

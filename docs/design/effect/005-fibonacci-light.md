# 005: フィボナッチ・ライト

## 概要

多数の光粒子を黄金角によって偏りなく全画面へ展開し、超必殺技の発動時に空間全体へエネルギーが満ちる様子を表現する共通エフェクトである。

## 動作モデル

同じ位置や方向へ粒子が重ならないよう、生成番号へ黄金角の係数を乗じて各粒子の方向を決定する。粒子は中心から螺旋状に分散し、初速度と加速度によって広がりながら消える。

黄金角係数を`k`として用途別初動パターンへ保存する。将来は`k`、生成数、粒子素材、倍率、速度および加速度の組合せを追加し、密度や螺旋の開き方が異なる派生表現として共有する。

重力球そのものの周辺粒子には含めない。超必殺技などが必要な時だけ独立したHelperとして発動する。

## 他エフェクトとの関係

青暗転および中心衝撃波と同時に使用できる。青暗転の上へ光粒子を描き、中心衝撃波とは同じ発生中心を共有できる。

# 002: Aura

## 動作モデル

本体に完全に重なるオーラを表示する。本体と同じアニメーションと描画オフセットを同期し、透過した外形として本体の周囲に現れる。

オーラは本体を基準に、100〜115%の範囲で周期的に拡大・縮小する。一定倍率で機械的に表示するのではなく、鼓動するような反復で存在感を表現する。

オーラには残像を付加する。拡大・縮小の動きと残像を重ねることで、単なる複製ではなく、身体から発せられるエネルギーの余韻として見せる。

頭部にも同じオーラ表現を付加する。head-auraはRootから生成し、頭部Helperに完全追従させ、頭部のアニメーションと描画オフセットを同期する。

## 実装方式

本体からオーラ用Helperを生成する。Helperが存在しない場合だけ生成し、同時に1体を超えないようにする。Helperは本体へ完全追従させ、位置は本体を基準にする。

Helperは毎フレーム本体（Root）のアニメーションへ追従させ、アニメーションの枚数も含めて同期する。オーラ用AfterImageは本体と同じ方式を使い、オーラ専用の倍率と残像長を設定する。

本体側の常時監視で専用Helperの存在を確認し、存在しない場合だけ生成する。Helperは専用の常駐ステートで本体への追従、アニメーション同期、鼓動倍率、透過、AfterImageを処理する。

## 現在の設定値

### オーラHelper

- 追従位置：本体基準 `Pos X/Y = 0,0`
- 同時存在数：1体以下
- 表示：透過
- アニメーション：Rootへ毎フレーム同期（枚数を含む）
- 描画オフセット：Rootの浮遊表示と同期

### 頭部オーラHelper

- 追従対象：頭部Helper
- 同時存在数：1体以下
- 表示：透過
- アニメーション：頭部Helperへ毎フレーム同期
- 描画オフセット：頭部Helperの浮遊表示と同期
- 拡大率：頭部の100〜130%

### 鼓動表示

- 拡大率：本体の100〜115%
- 動作：周期的な拡大・縮小
- 表現：鼓動する反復

### オーラAfterImage

- `palmul = 0.2,0.2,0.8`
- `mul = 0.1,0.4,0.4`
- `length = 128`

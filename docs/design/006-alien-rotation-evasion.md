# 006: Alien Rotation Evasion

## 動作モデル

TENKIKAIは、その場で柔軟な宇宙人的ボディを非人間的に回転させた後、画面から消失し、離れた場所へ出現する。人間が身をかわしたり跳躍したりする回避ではなく、身体構造と空間の両方が通常の生物とは異なることを見せる回避とする。

回転は消失へ移る前触れとして表示する。身体が異形の回転を終えた直後に全身が見えなくなり、しばらく何も表示されない時間を置く。その後、選択された別の場所へ突然出現する。回転と再出現の間に空白を置くことで、単なる高速移動ではなく、現在位置から存在そのものが抜け落ちたような断絶を表現する。

非表示中は、本体、頭部、胴体オーラ、頭部オーラを含むTENKIKAIの表示を消す。出現時には選択された領域へ全体が揃って戻り、部位やオーラが元の位置へ残らないようにする。

## 出現位置の選択

画面を上下二段、横三列の六領域として扱う。回転中の追加入力によって出現領域を選ぶ。

`X`、`Y`、`Z`は下段の左、中央、右に対応する。`A`、`B`、`C`は上段の左、中央、右に対応する。上下の段と横方向の列を一つのボタンで同時に選択できるため、回避中に複雑な方向入力を要求せず、六方向への空間移動を即座に指定できる。

この選択方式により、相手との距離を離すだけでなく、頭上、背後、画面中央などへ位置関係を大きく組み替えられる。回避後の展開を入力ボタンで選べるため、防御行動でありながら次の攻防へ能動的につながる。

## 状態・入力関係

`X+Y`の同時入力で回避を開始する。開始後は回転アニメーションを表示し、その間に受け付けた`X`、`Y`、`Z`、`A`、`B`、`C`の追加入力から出現領域を決定する。

回転終了後は非表示状態へ移り、選択済みの領域へ位置を変更してから再出現状態へ移る。回転、非表示、再出現は三つのStateDefに分けるが、一つの回避動作として連続させる。

回避状態の間は相手との位置衝突を無効にし、Helper Armorによる攻撃受付も停止する。回転中、非表示中、再出現までを一つの無敵な空間移動として扱い、途中で相手に押し戻されたり攻撃によって中断されたりしないようにする。

## 実装方式

回転にはStateDef `300`とAction `300`を使用する。Action `300`は回転を構成する各画像を2tickずつ表示する。回転中の追加入力を保持し、後続状態へ選択結果を渡す。

消失にはStateDef `301`とAction `301`を使用する。Action `301`は画面へスプライトを表示しない非表示専用アニメーションとする。非表示期間中に、追加入力で選択された画面領域へRootの位置を変更する。

再出現にはStateDef `302`を使用する。位置変更後に全表示要素を選択領域へ揃えて再表示し、回避動作を終了する。

StateDef `300`、`301`、`302`は、`the_controller`が管理するPlayerPush無効化フラグと無敵フラグの対象に追加する。Root側からHelper変数を直接変更せず、`the_controller`がRootのStateNoを監視して両方のフラグを設定する。

## 現在の設定値

### 回避開始

- StateDef：`300`
- Action：`300`
- 発動入力：`X+Y`
- 各画像の表示時間：`2` tick

### 消失

- StateDef：`301`
- Action：`301`
- 表示：非表示専用アニメーション

### 再出現

- StateDef：`302`

### 出現領域

- `X`：画面下段・左列
- `Y`：画面下段・中央列
- `Z`：画面下段・右列
- `A`：画面上段・左列
- `B`：画面上段・中央列
- `C`：画面上段・右列

### 非表示期間

- 非表示期間：回転アニメーション終了後から数秒間
- 非表示対象：本体、頭部、胴体オーラ、頭部オーラ

### 接触と攻撃受付

- PlayerPush：StateDef `300`～`302`の間は無効
- Helper Armorの攻撃受付：StateDef `300`～`302`の間は無効

### 未確定項目

- 非表示期間の具体的なtick数
- 各領域内での正確な出現座標
- 追加入力がない場合の出現領域

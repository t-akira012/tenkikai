# 014: 非常駐Helper共通実行基盤

## 概要

有限寿命のHelperが、表示、座標運動、攻撃判定などの複数責務を一体で継続的に実行するための共通基盤である。

各Helperは生成目的に応じた責務だけを持つ。巡回回転移動を必要としないエフェクトも専用の別基盤を持たず、同じ処理列で必要な責務だけを通過する。

## 処理周期

用途別の初期化は、責務、寿命、時間基準および個別調整値をHelper自身へ保存する。すべての初期化完了後に共通起点へ入る。

共通起点から各責務を固定順に一度ずつ評価し、寿命判定後に終端へ移る。終端は同一tick内の再進入を防ぎ、次tickに共通起点へ戻る。

表示、運動、周期生成および寿命はHelper私有経過tickによって進行する。StateDefの移動で進行状態を失わない。

## 責務の同時成立

既存のエフェクト本体責務は一体のHelper上で相互排他とし、同じ通常変数領域を共有できる。

今後追加する巡回回転移動と攻撃判定は、重力球や明光弾などの本体責務と同時に成立できる独立責務とする。同時成立する責務間では通常変数領域を重ねない。

## 実装契約

詳細な判断理由は[ADR 034](../ADR/034-transient-helper-responsibility-routing.md)に従う。

## 現在の設定値

### 共通StateDef範囲

- 予約範囲：StateDef `599000`〜`599999`
- 共通起点：StateDef `599000`
- 責務ルーター：StateDef `599010`〜`599100`
- 共通寿命判定：StateDef `599900`
- 共通終端：StateDef `599999`

### 責務ビット

- マスク`1`：楕円衝撃波
- マスク`2`：重力球
- マスク`4`：フィボナッチ・ライト
- マスク`8`：中心衝撃波
- マスク`16`：背景色変更
- マスク`32`：横線形衝撃波
- マスク`64`：明光弾
- マスク`128`：三次元巡回移動
- マスク`256`：攻撃判定
- マスク`512`：両手光弾発出管理
- マスク`1024`以降：将来の責務割当用

### 共通ヘッダー

- `sysvar(0)`：責務ビットマップ
- `sysvar(1)` bit 0、マスク`1`：初期化完了
- `sysvar(1)` bit 1、マスク`2`：終了要求
- `sysvar(2)`：Helper私有経過tick。生成tickは`0`
- `sysvar(3)`：最後に責務を実行する経過tick。アニメーション終了管理は`-1`
- `sysvar(4)`：未使用、将来の共通ヘッダー拡張用

### 固定実行順

- StateDef `599010`：楕円衝撃波
- StateDef `599020`：重力球
- StateDef `599030`：フィボナッチ・ライト
- StateDef `599040`：中心衝撃波
- StateDef `599050`：背景色変更
- StateDef `599060`：横線形衝撃波
- StateDef `599070`：明光弾
- StateDef `599080`：三次元巡回移動
- StateDef `599090`：攻撃判定
- StateDef `599100`：両手光弾発出管理
- Helper私有経過tickの更新：全責務完了後に1回
- StateDefの`time`使用：StateDef `599999`から次tickに復帰する`time>=1`のみ

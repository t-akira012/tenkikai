# 012: 地面隣接浮遊時の足元波紋

## 概要

TENKIKAIが地面近くでほぼ静止して浮遊しているとき、身体を支える力が地面へ届いた反応として足元へ波紋を生じさせる。身体そのものの移動が小さな時間にも空気と地面への作用を継続して示し、静止物ではない浮遊感を保つ。

この表現は接地、着地または砂埃を意味しない。移動の痕跡ではなく、浮遊中の圧力が周期的に地面へ伝わる表現とする。

## 動作モデル

地面に隣接し、水平移動がほぼ静止とみなせる間だけ、TENKIKAIの直下へ横長の小さな波紋を一定間隔で発生させる。波紋は地面上の生成地点へ残り、生成後のTENKIKAIへ追従しない。短い時間で横方向へ広がって消え、次の波紋との間に空白を持たせる。

水平速度が基準へ達した場合は、波紋を別の移動演出へ置き換えず、何も生成しない。速度の低下によって再びほぼ静止状態となった後は、周期条件を満たした時点から足元波紋を再開する。

## 利用エフェクト

[超高速射出空気波紋](effect/002-supersonic-air-ripple.md)の二円弧構成を、地面反応用の横長小波紋として利用する。高速射出用の縦長波紋とは用途番号と完成値を分け、共通の寿命管理だけを共有する。

## 現在の設定値

### 発生条件

- 地面隣接条件：Rootの`Pos Y`が`-20`以上
- ほぼ静止の条件：Rootの`abs(Vel X)`が`1`未満
- 非表示条件：Rootの`abs(Vel X)`が`1`以上
- 砂埃：生成しない

### 表示位置

- 水平位置：生成時のRootの直下
- 垂直位置：ステージ地面へ接して見える位置
- Sprite軸の垂直補正：ステージ地面座標から下方へ`26px`
- 生成後のRoot追従：なし

### 波紋

- 利用エフェクト：`effect-002`の足元波紋
- 表示形状：横長の小波紋
- Helper用途番号：`500020`
- 左右円弧：StateDefおよびHelper ID `500020`・`500021`
- 生成間隔：24tick
- 寿命：20tick
- 初期倍率：X `0.38`、Y `0.03`
- 終了倍率：X `0.85`、Y `0.10`
- 描画優先順位：奥側円弧`-1`、手前側円弧`100`
- X速度：`0`px/tick

# 015: 石の自由落下を思わせる回避復帰モーション

## 動作モデル

画面上方または下方に現れたTENKIKAIが、重力に引かれる石のように落下し、特定位置で一度だけ跳ね返る。その後いったん姿を消し、地上へ回避復帰のように再出現する。通常の浮遊移動とは異なる落下と反転を短く見せ、空間上の一点を仮想的な床として扱う。

## 状態・処理関係

初期出現位置は画面中央のX位置とし、画面高の上から約20%または約80%の位置を交互に使う。出現時の本体アニメーションには両手光弾発出を流用し、上下反転して表示する。出現時の縦長から通常形状への復元には、異形回避復帰の全身復元を流用する。

出現後は下向き加速度で落下する。実際の地面へ接触させず、画面高の約92%に設定した技専用の位置で一度だけ上向きに反転させる。この位置を仮想的な床として扱う。跳ね返った後、回避復帰の非表示時間を流用して消え、画面中央X・地上へ回避復帰の全身復元を流用して再出現する。

## 入力と置換対象

- 発動ボタン：`Y`。既存のオーラバウンド保持・縮小確認StateDef `4002`の入力を本モーションへ置き換える。
- 既存のテスト用モーションを本モーションへ置き換える。
- 技本体はStateDef `1300`〜`1304`を使用する。既存のStateDef `4002`への`Y`入力遷移を置き換える。

## 現在の設定値

### 出現位置・移動

- 出現位置：画面中央X。上側は上端から48px、下側は上端から192px（画面高240pxに対する20%・80%）。発動ごとに交互に切り替える（試験値）
- 仮想的な床となる折り返し位置：上端から220px（画面高の約92%、試験値）
- 落下加速度：下向き`1.5px/tick²`（試験値）
- 折り返し時の上向き速度：`10px/tick`（試験値）
- 跳ね返り区間：StateDef `1302`で13tick（試験値）
- 出現時の復元：16tick
- 消失時間：8tick
- 地上再出現後、Rootが操作へ戻るまで：2tick

### 表示・復帰

- 出現時の本体アニメーション：Action `1000`（両手光弾発出）を流用し、Bodyを上下反転
- 初期出現と地上への再出現：異形回避復帰の全身復元を流用
- 消失：異形回避の非表示StateDef `301`相当の表示制御
- 地上への復帰位置：地上

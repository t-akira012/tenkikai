# 015: 石の自由落下を思わせる回避復帰モーション

## 動作モデル

Y入力で全身を縦長に変形させて姿を消し、画面上部へ移ってから上下反転した姿で現れる。斜めに落下する途中で身体を起点とした分岐電撃を放ち、周囲の動きを一時停止する。落下後は再び姿を消し、地上へ回避復帰のように再出現する。落下中に仮想的な床で跳ね返る処理はない。

## 状態・処理関係

開始時は現在位置で全身の倍率を変化させ、その後、非表示のまま待機する。再出現時には現在位置から前方へ移し、画面上端を基準に高さを合わせる。本体アニメーションには両手光弾発出を流用し、上下反転した縦長の姿を通常形状へ戻す。

落下は最初に斜め方向へ加速し、その後は別の一定速度へ切り替える。落下中に分岐電撃Helperを生成し、同時にSuperPauseを開始する。落下後も短時間は現在の速度を引き継ぎ、全身を再び縦長に変形させる。その後、非表示のまま画面端付近の地上へ移り、通常形状へ戻って操作可能な状態へ復帰する。

## 入力と置換対象

- 発動ボタン：`Y`。既存のオーラバウンド保持・縮小確認StateDef `4002`の入力を本モーションへ置き換える。
- 既存のテスト用モーションを本モーションへ置き換える。
- 使用StateDef：`1306`→`1305`→`1300`→`1301`→`1307`→`1303`→`1304`→`0`。

## 現在の設定値

### 開始・出現

- StateDef `1306`：現在位置で8tick待機する。Body系はX倍率`1.0`→`0.2`、Y倍率`1.0`→`3.0`へ変形する。
- StateDef `1305`：Action `301`で40tick非表示にし、速度を`0,0`へ設定する。
- StateDef `1300`：進入時にRootを向き基準で前方`40px`、画面上端から`20px`へ移す。Action `1000`で8tick表示する。Body系の上下反転復元は8tickで、X倍率`0.2`→`1.0`、Y倍率`-3.0`→`-1.0`とする。

### 落下・電撃

- StateDef `1301`：開始時のX速度は`-3.65625px/tick`。最初の8tickはY速度に毎tick`1.6145833333333333px/tick`を加える。`time=8`で速度をX `-0.40625px/tick`、Y `1.5625px/tick`へ設定し、`time>=20`でStateDef `1307`へ進む。
- StateDef `1301`の`time=10`：分岐電撃Helper `510000`を1体生成し、20tickのSuperPauseを開始する。Rootの`movetime`は`0`、電撃Helperは停止中も動作する。
- 電撃発出中のRoot描画優先順位：StateDef `1301`の`time=10`で`5`に変更し、SuperPause終了後の`time=11`で通常値`2`へ戻す。主光球の`4`、背後光球の`3`より前に本体を表示する。
- StateDef `1307`：速度を再設定せず8tick継続し、全身をX倍率`1.0`→`0.2`、Y倍率`-1.0`→`-3.0`へ変形する。
- 落下中のBody系傾斜目標：`20`度。上下反転を維持する処理はStateDef `1301`と`1307`で毎tick更新する。

### 非表示・地上復帰

- StateDef `1303`：Action `301`で8tick非表示にする。進入時にX位置を画面座標から計算して補正し、Y位置を地上の`0`へ設定する。速度は`0,0`へ設定する。
- StateDef `1304`：Action `0`で2tick待機後、操作可能なStateDef `0`へ戻る。Body系は8tickの全身復元を開始し、StateDef `0`へ戻った後も残り時間を継続する。
- StateDef `1300`〜`1307`：Helper Armorの攻撃受付を無効にする。

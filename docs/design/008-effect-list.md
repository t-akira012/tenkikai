# エフェクト一覧

## 概要

TENKIKAIの技や状態に伴う暗転、発光、色変化、フラッシュなどの視覚エフェクトを、技をまたいで識別できるように整理する。

新しいエフェクトは実装前に本一覧へ登録し、表現目的、見た目、適用対象、使用場面を確定する。同じエフェクトを複数の技から使用する場合は、新しいエフェクトとして重複登録せず、既存の表現を共有する。

CNS上のStateDef、Controller、Trigger、変数、ルーティングなどの実装内容は、[the_controllerステート文書](../state/helper-99004-the-controller.md)など、`docs/state/`の対応文書で管理する。

## エフェクト番号0：全画面黒

### 表現

画面全体の色を完全な黒へ変化させる。個々の表示要素だけを隠すのではなく、画面全体へ同じ色変化を適用する。

### 使用場面

汎用両手光弾発出の予備動作中に開始する。エフェクトは発動元の状態が終了した場合も、設定された継続時間が残っている間は継続する。

## 現在の設定値

### エフェクト番号0：全画面黒

- エフェクト番号：`0`
- 適用対象：画面全体
- 色変化：乗算値`0,0,0`
- 発動元：RootのStateDef `1000`
- 発動時刻：`private-time=10`
- 継続時間：60tick
- 色指定個別StateDef：`99004100`

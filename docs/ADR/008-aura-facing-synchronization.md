# ADR 008: Auraの向きと傾斜の同期

## 状態

採用

## 背景

ダッシュ中のAuraはRootと同じ方向へ傾斜する必要がある。Rootの向きを参照した角度へ補正値を加えるだけでは、Aura自身の左右反転と傾斜の関係が分散し、表示方向が逆になる。

## 決定

Root、頭部、Body aura、Head auraの`facing`を一致させる。各HelperはRootに合わせて`Turn`し、向きの状態を同期する。前後ダッシュに合わせてBody auraを傾斜させ、頭部を位置移動させる。

この3段階以外の独立した向き計算、角度の符号補正、表示要素ごとの別基準は導入しない。

## 結果

左右反転とダッシュ傾斜の基準がAura内で一貫する。RootとAuraの向きが変わっても、補正値による左右反転に依存せず同じ見た目を維持できる。

# ADR 008: Auraの向きと傾斜の同期

## 状態

採用

## 背景

本体自由傾斜中のAuraはRootと同じ方向へ傾斜する必要がある。Rootの向きを参照した角度へ補正値を加えるだけでは、Aura自身の左右反転と傾斜の関係が分散し、表示方向が逆になる。

## 決定

Root、頭部、Body aura、Head auraの`facing`を一致させる。各HelperはRootに合わせて`Turn`し、向きの状態を同期する。Body auraは`the_controller`が完成させた本体自由傾斜角度を使用し、頭部は同じ現在角度から完成位置を求める。自由傾斜の要求と計算は[ADR 029](029-body-free-tilt-request.md)に従う。

この3段階以外の独立した向き計算、角度の符号補正、表示要素ごとの別基準は導入しない。

## 結果

左右反転と本体自由傾斜の基準がAura内で一貫する。RootとAuraの向きが変わっても、補正値による左右反転に依存せず同じ見た目を維持できる。

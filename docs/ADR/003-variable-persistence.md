# ADR 003: ラウンド持ち越し変数の範囲

## 状態

採用

## 背景

通常変数のうち、ラウンドごとに初期化する変数と、勝利・敗北時の特殊演出などで次のラウンドへ引き継ぐ変数を分離する必要がある。

## 決定

`cns/constants.cns` の `IntPersistIndex` を `50` とする。

この設定により、ラウンド開始時に `var(0)`～`var(49)` を0へリセットし、`var(50)`～`var(59)` はラウンド間で持ち越す。

`var(50)`～`var(59)` は、敗北・勝利時の特殊演出など、ラウンドをまたいで状態を保持する必要がある処理に使用する。

別の試合へ変数を持ち越すことはできない。`SysVar` と `SysFVar` も持ち越さない。

## 結果

`private-gametime`、`private-time`、AfterImage制御用 `var(10)` などの通常処理用変数はラウンドごとに初期化される。一方、`var(50)`～`var(59)` はラウンド間の特殊演出用スロットとして確保される。

# ADR 036: 接地許可フラグによる共通接地処理

## 状態

採用

## 背景

接地位置補正、速度補正、StateType/Physics設定が別々の位置・入力条件で接地を判断していた。技固有StateDefごとにこれらのControllerへ除外条件を追加すると、接地処理の意味が分散し、一部だけ接地が発動する可能性がある。

## 決定

接地許可フラグをRootの`var(2)` bit 17（マスク`131072`）に置く。StateDef `-3`は接地処理より前に毎tick bit 17を消去し、画面横断突進のStateDef `1200`〜`1204`以外で再設定する。突進の全区間では、角度や位置にかかわらず常に解除する。

StateDef `-3`の位置補正、速度補正、接地時の移動要求解除および地上StateType/Physics設定は、既存の接地条件に加えてこの許可フラグを参照する。フラグが解除中は共通接地処理を実行しない。通常の接地判定条件は維持し、bit 17はCommand入力に割り当てない。

## 結果

接地処理の許可・抑止を一つのRoot状態bitに集約する。通常の接地判定は従来条件のまま維持し、画面横断突進中だけStateDef `-3`がbitを解除して共通接地処理全体を抑止する。

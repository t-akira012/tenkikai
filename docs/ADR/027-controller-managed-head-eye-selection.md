# ADR 027: Head眼球表示をControllerで完成させる

## 状態

採用

## 背景

Headは通常時、相手との符号付き水平距離から眼球位置の異なる頭部画像を選択する。今後は特定の技において、相手との距離にかかわらず特定の眼球位置を表示する演出も予定されている。

距離判定と技固有条件をHeadへ集約すると、技が増えるたびに表示HelperへRootのStateDef知識が追加される。通常追従と技固有指定の優先順位もHead内のState Controller順へ依存する。

## 決定

Head眼球表示の選択は`the_controller`が完成させ、`var(24)`のビットフィールドへ保持する。

- bit 0：相手との距離による眼球位置同期
- bit 1：Sprite `1,1`を使用する完成表示
- bit 2：Sprite `1,2`を使用する完成表示
- bit 3：Sprite `1,3`を使用する完成表示

`the_controller`は毎tick、`var(24)`を距離同期だけが有効な値へ初期化する。眼球表示ルーターは技固有の固定表示を0個または1個選択し、該当しない場合は距離同期を実行する。

前方ダッシュStateDef `110`と後方ダッシュStateDef `111`は固定表示を選択し、距離同期bitを解除してSprite `1,1`の完成表示bitだけを設定する。

距離同期ではbit 0を維持したまま、相手との符号付き水平距離からbit 1〜3の一つだけを完成表示として設定する。技固有の固定表示ではbit 0を無効にし、bit 1〜3の一つだけを設定する。同じtickに複数の完成表示bitを設定しない。

Headは`the_controller`のbit 1〜3だけを読み、対応する単一要素Action `99001`、`99011`、`99012`を表示する。距離、RootのStateDef、技固有条件をHeadで再判定しない。Head AuraはHeadのActionと要素位置へ同期する。複数の無限時間要素を一つのActionへ置き、後続要素へ直接切り替える構成は使用しない。

## 結果

通常の距離追従と技固有の固定視線が同じ完成表示経路を使用する。技固有視線を追加してもHeadとHead AuraへStateDef条件を追加せず、`the_controller`の眼球表示ルーターだけを拡張できる。

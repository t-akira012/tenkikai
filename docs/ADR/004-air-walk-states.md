# ADR 004: 空中歩行ステートの導入

## 状態

採用

## 背景

浮遊中も前歩き・後ろ歩きを利用できる必要がある。入力によるStateDef遷移と、浮遊中の物理処理を適切な常時監視ステートへ分離する。

## 決定

空中前歩きに `StateDef 60`、空中後ろ歩きに `StateDef 61` を使用する。

`holdfwd` と `holdback` を検知したStateDef `-1` から、それぞれ `StateDef 60` と `StateDef 61` へ遷移する。入力に起因する遷移をStateDef `-3`には置かない。

StateDef `60` と `61` は `type=A`、`physics=N` とし、浮遊中の前後移動を各ステートで処理する。向きはM.U.G.E.Nの自動反転に従い、移動量の計算で `facing` を参照しない。

浮遊位置、重力、接地補正はStateDef `-3`で継続する。StateDef `-2`はState奪取中も機能する完全な常時監視として、private時間や強制復帰などを担当する。

## 結果

空中歩行の入力遷移と浮遊物理の責務が分離され、地上用 `StateDef 0` の処理と空中歩行の移動処理が混在しない。空中歩行中に入力を切り替えた場合は `StateDef 60` と `61` の間で遷移し、前後入力を解除した場合は `StateDef 0` へ戻る。

# ADR 019: Rootアニメーション時間のController保持

## 状態

採用

## 背景

Rootのアニメーション進行に同期する複数のHelperは、現在の`AnimTime`だけでなく、アニメーション開始時点の`AnimTime`絶対値を必要とする場合がある。この値はアニメーションの要素数や各要素の表示時間によって変わるため、利用側が固定値を持つとAIR変更へ追従できない。

各Helperが同じ値を個別に検出して変数へ保存すると、限られたHelper変数を重複して消費し、検出条件と更新順序も分散する。Rootを常時監視する`the_controller`が共通情報として一度だけ保持し、利用側へ提供する必要がある。

## 決定

Rootアニメーション番号と、アニメーション変更時の`abs(root,animtime)`を`the_controller`が保持する。

`the_controller`の`var(15)`を保存済みRootアニメーション番号、`var(16)`をアニメーション変更時の`AnimTime`絶対値とする。変更検出時は、先に`var(16)`を更新し、その後で`var(15)`を更新する。

利用Helperは自身の変数へ同じ情報を保存しない。`helper(99004),var(15)`が現在の`root,anim`と一致し、かつ`helper(99004),var(16)`が正の場合だけ、保存済み時間を使用する。値が一致しないフレームは古いアニメーション情報を使用せず、Controllerの更新を待つ。

具体的な利用StateDefや演出は本ADRの対象としない。Rootアニメーション時間を必要とするすべてのHelperへ適用する汎用契約とする。

固定的な実装制約は[Rootアニメーション時間保持規約](../AGENTS.root-animtime.md)に定める。

## 結果

アニメーション要素数や各要素の表示時間が変更されても、利用HelperはControllerがアニメーション変更時に取得した時間を基準に追従できる。

Rootアニメーション時間の保存責務と変数消費が`the_controller`へ集約され、表示Helperごとの重複変数と固定時間を排除できる。Helper間の実行順によって更新が同一フレームに見えない場合も、アニメーション番号の一致確認によって古い値の誤用を防止できる。

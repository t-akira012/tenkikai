# ADR 035: CNSを文書同期の正本とする

## 状態

採用

## 背景

CNS実装と設計文書、技仕様文書、State文書または変数文書に差異がある場合、どちらを基準に同期するかが文書群ごとに異なっていた。実機調整中の値を文書へ記録しない運用では、現行挙動を文書から追跡できず、後続変更で古い値を実装へ戻す危険がある。

## 決定

CNS実装とリポジトリ内文書に差異がある場合は、常にCNSを正本とする。CNSの動作、数値および処理関係を変更せず、設計文書、技仕様文書、State文書および変数文書を現行実装へ同期する。

実機調整中または暫定の値も現在値として文書へ記録する。確定状態と混同する可能性がある場合は、値を省略せず「試験中」などの注記で状態を区別する。

## 結果

- 文書だけに残る旧値を根拠としてCNSを巻き戻さない。
- 現行実装の挙動と設定値を文書から確認できる。
- 実機検収では値そのものではなく、試験中・確定済みの状態注記を更新する。

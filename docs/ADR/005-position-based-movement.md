# ADR 005: 位置加算による移動とデフォルト速度の排除

## 状態

採用

## 背景

地上・空中の歩行を `VelSet` に依存させると、速度が次のフレームへ保持され、入力解除後も意図しない移動が継続する。TENKIKAIでは入力による移動を位置加算として明示的に管理する必要がある。

## 決定

キャラクターの歩行・浮遊歩行など、入力に起因する移動は `PosAdd` で実装する。歩行ステートでは水平速度を `0` に固定し、M.U.G.E.Nのデフォルト速度処理による水平移動を排除する。

`cns/constants.cns` の `[Velocity]` に定義されるデフォルト移動速度は、歩行・走行・ジャンプ・空中ジャンプを含めて全て `0` とする。これらのデフォルト速度を入力移動へ使用してはならない。

入力移動量は各移動処理の `PosAdd` に明示し、`cns/constants.cns` の速度定数を参照しない。現在の移動量は設計文書に集約する。`Vel` は重力、被弾、その他の物理挙動に限定し、入力移動の水平速度には使用しない。

なお、`tenkikai.def` には移動速度を定義するセクションがない。デフォルト速度は `cns/constants.cns` で0にし、実際の入力移動は各ステート内でエミュレートする。

## 結果

入力を離した時点で位置加算が停止し、デフォルト速度や水平速度の残留による移動が発生しない。重力や被弾によるY方向の速度は引き続き `Vel` で処理できる。

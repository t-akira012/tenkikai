# ADR 011: アニメーション定義をcnsへ移動する

## 状態

採用

## 背景

`animation.air`は画像や音声のバイナリではなく、WinMUGENのActionを記述するテキストファイルである。バイナリ素材と同じ`binary/`へ置くと、ファイル形式とディレクトリ構成の意味が一致しない。

## 決定

アニメーション定義を`binary/animation.air`から`cns/anim.air`へ移動する。`tenkikai.def`の`anim`参照、フォーマッター、検証スクリプト、コーディング規約も新しいパスへ統一する。

## 結果

テキスト形式のCNS関連定義が`cns/`に集まり、`binary/`には画像・音声・パレットなどのバイナリ素材だけが残る。WinMUGENから参照されるAction定義の内容は変更しない。

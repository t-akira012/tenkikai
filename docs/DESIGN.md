# TENKIKAIキャラクターデザイン

設計文書：[design/](design/)

## キャラクター像

TENKIKAIは、地面へ立つ一般的な格闘キャラクターではなく、常に空中へ浮遊しているキャラクターである。待機中も本体と頭部が独立した周期で上下し、静止していても浮遊感を示す。

## 基本移動

基本移動は前進、後退、前方ダッシュ、後方ダッシュで構成する。しゃがみとジャンプは通常操作として使用しない。上下方向を含む将来の移動は、一般的なジャンプの流用ではなく、TENKIKAI固有の浮遊移動として設計する。

## 攻撃

KFM由来の通常技、投げ、必殺技、超必殺技は採用しない。攻撃体系はTENKIKAIのキャラクター性に基づいて改めて設計するため、現段階では攻撃手段を定義しない。

## システム挙動

ガード、被弾、吹き飛び、ダウン、受け身、KO、登場、勝利、ラウンド初期化など、対戦を成立させるためのシステムステートは維持する。ただし、一般的な相手攻撃によるライフ減少は本体への直接被弾を前提とせず、Helper Armor式ライフ管理を使用する。相手の処理によって空中へ移された場合の着地も安全に処理する。

## ライフ管理

TENKIKAIは原作作品における特殊な強者として、宇宙的で極めて頑強な肉体と非常に硬質な外殻を持ち、一般的な攻撃がほとんど通用しない存在として表現する。ゲーム上では通常の本体被弾ではなく、Helper Armorによって攻撃情報を受け取り、仮想的に本体ライフへ反映する。

ライフが減少した場合は自動的に再生し、低ライフ時には受けるダメージをさらに減衰させることで、単純な高ライフではない倒しにくさを作る。詳細は[ライフ管理方式](design/005-life-management.md)に定める。

# TENKIKAIキャラクターデザイン

設計文書：[design/](design/)

## キャラクター像

TENKIKAIは、地面へ立つ一般的な格闘キャラクターではなく、常に空中へ浮遊しているキャラクターである。待機中も本体と頭部が独立した周期で上下し、静止していても浮遊感を示す。

## 基本移動

基本移動は前進、後退、前方ダッシュ、後方ダッシュで構成する。しゃがみとジャンプは通常操作として使用しない。上下方向を含む将来の移動は、一般的なジャンプの流用ではなく、TENKIKAI固有の浮遊移動として設計する。

## 攻撃

KFM由来の通常技、投げ、必殺技、超必殺技は採用しない。攻撃体系はTENKIKAIのキャラクター性に基づいて改めて設計するため、現段階では攻撃手段を定義しない。

## システム挙動

ガード、被弾、吹き飛び、ダウン、受け身、KO、登場、勝利、ラウンド初期化など、対戦を成立させるためのシステム挙動は維持する。相手の攻撃によって空中へ移された場合の着地も安全に処理する。

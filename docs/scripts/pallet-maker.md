# pallet-maker仕様

## 目的

指定ディレクトリのうち、グループ番号が`10000`未満のPNGから色を抽出し、WinMUGEN用のACTパレットを生成する。既存の固有パレットを外部ACTへ無理に合わせるのではなく、既存スプライトの色を原典として`pal1.act`を作り直す。

## 入力対象

ファイル名の先頭をグループ番号として解釈する。`0000_0000.png`のように`グループ番号_画像番号.png`の形式を持ち、グループ番号が`10000`未満のPNGだけを対象にする。`10000`以上の素材や番号を解釈できないPNGは対象外とする。

最初の対象ファイル`0000_0000.png`の左上1pxのRGBを透明色として、ACTの先頭色へ配置する。アルファがあるPNGでも、透明色の原典はこの左上1pxである。

## ACTのインデックス

ACTは256個のRGB三連値をインデックス順に並べた768バイトのファイルである。SFFの共有パレット画像は画素の番号をACTの同じ番号として解釈するため、色を並べ替えただけのACTを作ってはならない。本ツールは走査順に色を一度ずつ登録し、インデックス0を透明色として予約する。SFF生成側も同じ`binary/pal1.act`を使って共有画像をインデックス化する。

透明色と同じRGBを持つ不透明画素が存在する場合、そのRGBはインデックス0以外にも登録する。これにより透明画素と不透明黒などを同一視しない。

## 色数制限

透明色を含む抽出色が256色を超えた場合はエラーとして終了し、ACTを生成しない。256色以下の場合は残りのパレットスロットを黒で埋め、768バイトのACTとして出力する。色の登録順は画素の走査順に固定し、RGB値のソートは行わない。

## CLI

```console
pallet-maker \
  --input assets/sprites/ \
  --output binary/pal1.act
```

Makefileからは次のコマンドで実行する。

```console
make pallet-maker
```

処理対象、走査中のファイル、色数、出力先を端末へ表示する。Pythonの実行と依存関係はscripts共通規約に従ってuvで管理する。

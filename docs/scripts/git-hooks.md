# Git hooks

## 目的

コミット前にリポジトリ全体の整形、検査、文書一覧生成を実行し、生成物と実装の不一致をコミットへ持ち込まない。

## 有効化

リポジトリ直下で次を一度実行する。

```console
make hooks
```

このコマンドはGitの`core.hooksPath`を`.githooks`へ設定する。

## pre-commit

コミット時に`make run`を実行する。`make run`が失敗した場合はコミットを中止する。

フォーマッターまたは文書一覧生成によって未ステージ差分が生じた場合もコミットを中止する。表示されたファイルを確認してステージし直した後、再度コミットする。

# Git hooks

## 目的

コミット前にリポジトリ全体を非書込みで検査し、未整形ファイルや生成物と実装の不一致をコミットへ持ち込まない。

## 有効化

リポジトリ直下で次を一度実行する。

```console
make hooks
```

このコマンドはGitの`core.hooksPath`を`.githooks`へ設定する。

## pre-commit

コミット時に`make check`を実行する。`make check`が失敗した場合はコミットを中止する。

`make check`はフォーマッターと文書一覧生成を検査モードで実行し、ファイルを書き換えない。要整形または要更新のファイルがある場合は、`make run`で明示的に更新し、内容を確認してからコミットする。

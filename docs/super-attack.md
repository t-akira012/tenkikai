# 超必殺技ステート

この文書は、1000パワーを消費するTENKIKAIの超必殺技を説明する。両技とも地上で使用し、通常技または必殺技の接触時にもキャンセルで開始できる。

## StateDef 3000: 三連カンフー掌底

入力は下、右下、右を2回入力して弱パンチまたは強パンチである。1000パワーを消費し、Action `3000` を再生する。

Action要素2でSuperPause、効果音、残像を開始する。発動直後には通常・必殺属性と投げに対する一時的な無敵があり、続く攻撃中はしゃがみ通常攻撃も無効化する。

前進しながらAction要素5、13、21で3回攻撃する。前2回は各72ダメージ、最後は75ダメージで、全段命中時の直接ダメージは219である。最後の一撃は相手を浮かせ、受け身を禁止する。アニメーション終了時にStateDef `0` へ戻る。

## スマッシュカンフーアッパー

入力は下、左下、左を2回入力して弱パンチまたは強パンチである。1000パワーを消費し、相手を大きく上空へ打ち上げる。

### StateDef 3050: 打ち上げ攻撃

Action `3050` を再生する。Action要素2でSuperPause、効果音、残像を開始し、通常・必殺属性と投げに対する短時間の無敵を得る。

攻撃は155ダメージと12のガードダメージを持ち、相手へY速度-25を与える。受け身を禁止し、落下時に70の追加ダメージと画面振動を発生させる。命中するとStateDef `3051` へ移り、空振り時はアニメーション終了後にStateDef `0` へ戻る。

### StateDef 3051: 命中後の終了動作

Action `3051` を再生し、残像を終端まで維持する。アニメーション終了時にStateDef `0` へ戻り、操作を可能にする。

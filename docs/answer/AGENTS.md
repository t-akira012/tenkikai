# ユーザー回答文書の規約

## 文書群の責務

`docs/answer/`は、CodexがWinMUGEN仕様についてユーザーへ質問し、ユーザーの回答によって確定した仕様を記録する。

## 記載対象

質問対象となった仕様、ユーザーが確定した回答、および回答から直接確定できる実行上の結果だけを記載する。

Codexの推測、一般的な実装助言、未確認の挙動、ウェブ情報は記載しない。追加調査によって回答と異なる可能性が生じた場合も、既存回答を独断で変更せずユーザーへ確認する。

## 他文書との関係

`docs/researched/`は、公式ドキュメントに記載されていないユーザー調査情報を扱う。`docs/answer/`は、Codexの質問に対するユーザー回答を原典とする。

実装やステート文書がユーザー回答と異なる場合は、回答へ機械的に合わせず、差異をユーザーへ提示して指示を受ける。
